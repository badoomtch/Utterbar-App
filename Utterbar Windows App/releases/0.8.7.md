# Utterbar 0.8.7

Three fixes from real-world use of the multi-engine catalogue introduced in 0.8.

## Models

- **Whisper actually loads now.** v0.8.6's Whisper providers errored with `tokens.txt not found` on every install attempt. The k2-fsa Whisper bundles use `<base>-tokens.txt` and `<base>-encoder.int8.onnx` / `<base>-decoder.int8.onnx` rather than the bare names the resolver assumed. The Whisper resolver now finds the right files (and prefers the int8 variants for CPU performance).
- **Zipformer no longer SHOUTS.** The English Zipformer bundle ships an all-caps token vocabulary, so transcripts came out in solid uppercase. We now lowercase Zipformer output before the standard auto-capitalise pass — produces normal sentence-case text, matching what Parakeet and Whisper return naturally.

## Auto-update

- **Beta channel.** Settings → Advanced → "Receive beta releases" toggles your install onto the beta update channel. Off by default. The updater check sends your channel as a query parameter; the server filters releases by exact channel match. Stable users never see beta releases. Lets the maintainer dogfood pre-release builds without polluting the public stable train.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
