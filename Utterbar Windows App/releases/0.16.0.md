# Utterbar 0.16.0

First stable release since v0.15.6 in late April. Bundles the v0.15.7 to v0.15.12 beta line: ASR output validation across every transcribe surface, an auto-stop on regular dictation, and a B2B layer covering managed fleet licences, air-gapped activation, and volume self-serve checkout. Local-only, Windows-first, £39.99 one-time.

## Reliability improvements

### Single-shot recordings auto-stop before the 5-minute cap

Regular dictation now auto-stops at around 4 minutes 55 seconds to keep the offline ASR engine away from its long-input limit. The success pill carries a clear notice: "Auto-stopped at 5 min. Use Meeting Mode for longer recordings." Whatever was captured before the cap is preserved in history; no transcript is lost. Meeting Mode is unaffected (it chunks internally and handles roughly an hour).

### Output validation across every transcribe surface

All three transcribe paths now drop obvious junk before it reaches the user:

- Regular dictation drops empty, whitespace-only, single-punctuation, and 10-plus repeated-punctuation outputs.
- File transcription validates the same shape on the whole-file pass.
- Meeting Mode validates each 29-second chunk as it stitches the transcript, so one bad chunk no longer ruins an otherwise-good meeting. Foreign-script chunks pass through unchanged. Repeated-token chunks (a Whisper decoder loop) are observed but not dropped, because real meeting speech occasionally carries sustained repetition.

Every drop is logged with the rule that fired so support can reproduce.

## For your IT team: managed fleet licences

If your IT team has an Utterbar Pro licence to roll out across a fleet, drop a signed `licence.bin` at `%APPDATA%\Utterbar\licence.bin` on each managed machine. The desktop verifies the file offline at startup and treats it as the active Pro licence. The user never sees an activation dialog. Removal is "delete the file".

Behaviour worth knowing:

- The admin downloads the file from the new "Download licence.bin" button on each licence detail page in the admin panel.
- A managed `licence.bin` overrides any user-pasted licence cache on the same machine.
- An invalid managed file (corrupt, wrong length, signed with a key the app does not recognise) reports as Free, logs a warning, AND blocks paste-flow activation. An admin who deployed a broken file gets a clear "no Pro" signal until they fix or remove the file; they cannot be undermined by a user pasting their own key as an override.
- Activation and device removal are disabled in-app on managed machines. The Settings panel renders a short "Managed by your administrator" notice instead of the activation form.

### Three new IT policy keys

Three additional DWORD values under the existing `HKLM\SOFTWARE\Policies\Utterbar` registry key (with `HKCU` as a fallback). These join the original five (`UpdateChannel`, `CheckUpdatesAutomatically`, `BlockModelDownloads`, `BlockSystemAudio`, `RequireLicence`) for a total of eight pinnable values.

- `BlockHistory` (REG_DWORD, 0 or 1). When 1, Utterbar does not persist new history rows. Existing rows are not deleted; the policy is forward-only.
- `BlockHistoryExport` (REG_DWORD, 0 or 1). When 1, the "export history as JSON" command refuses. History stays visible in the in-app History page; only the off-device copy is disabled.
- `BlockTelemetry` (REG_DWORD, 0 or 1). When 1, the local on-device analytics rollup that powers the Dashboard counters does not bump on a successful dictation. There is no remote telemetry; this gates the local SQLite rollup only.

The Privacy settings page surfaces a "Disabled by your administrator" hint when any of these are set. Policy changes require an Utterbar restart, same contract Windows itself has for most managed policies.

## For your IT team: air-gapped activation

For machines that cannot reach utterbar.com at all (lab kit, restricted-network admin VMs, classified-environment workstations), Utterbar now supports a fully offline activation flow. Six steps, no network from the offline machine:

1. On the offline machine, open Settings, Licence, and click "Export activation request". Utterbar writes a small JSON file (around 250 bytes) carrying the machine fingerprint, device name and app version.
2. Hand-carry the file to your IT administrator. Email, USB stick, internal share, whatever your network policy allows.
3. The administrator signs in to the admin panel, opens the licence detail page, and uses the new "Air-gapped activation" upload form. The server validates the format, counts the device against `max_devices`, and records an activation row marked offline.
4. The administrator clicks "Download licence.bin" on the same page.
5. Send the `licence.bin` back to the offline machine.
6. Click "Import licence.bin" in Settings, Licence. Utterbar verifies the signature offline, copies the file to `%APPDATA%\Utterbar\licence.bin`, and asks you to restart. Restart Utterbar; the next launch picks the file up via the existing managed-licence loader.

## Volume self-serve checkout

The pricing page now sells multi-seat licences directly through Stripe Checkout: 5 to 100 seats, with a tier boundary at 25 seats (£29 per seat below, £19 per seat at and above). One licence per order, `max_devices = quantity`, same Ed25519-signed blob format as single-user. Multi-seat orders above 100 seats continue to go through the `/business` enquiry path.

The admin licence detail page gets a Volume hero label, a dedicated "Volume / fleet deployment" card with a primary "Download licence.bin" button, and the new "Air-gapped activation" upload form on every licence detail page. The admin licences index gets a Type column with a Volume chip and an emphasised seat count for volume rows.

## Honest revenue accounting

The admin dashboard Gross / Net of refunds tiles previously assumed every licence was the single-user Pro amount. They now SUM the actual `amount_total` Stripe reports for each row, captured at mint time so a future price change does not retroactively rewrite history. A new "Untracked rows" tile flags how many rows lack a captured amount (admin manual mints plus any pre-2026-05-02 Stripe row, which we deliberately do not backfill).

## Known limitations carried forward

Honest about the edges this release ships with:

- The air-gapped `licence.bin` is not machine-bound in this version. The file is the same bytes for every device on the licence; a v3 fingerprint-bound payload is on the parking lot for buyers who need hard binding. Mention it in your enquiry. The 0.15.12 admin upload records audit and `max_devices` intent rather than a cryptographic binding.
- Offline devices never heartbeat. Revocation only takes effect on devices that contact the server; air-gapped devices keep running until their `licence.bin` is replaced or removed on disk.
- A code-signed installer for fleet rollouts is signed at order time, not part of the public stable line. SmartScreen warnings are expected on first install for the public download. Mention "signed installer" in your enquiry and we will fold the cert cost into the quote.
- DirectML on Whisper Small still routes to CPU on Auto, since CPU is faster on the test hardware. Revisit on hardware where the ratio reverses.
- Speaker labels on Meeting Mode are still off. The architectural rework remains parked behind unstable ASR/runtime questions.

## What this release does not change

- Pricing: still £39.99 GBP one-time for single-user Pro, three-device cap.
- Local-only: nothing leaves your machine. No cloud, no account for the app, no subscription.
- Licence trust model: same Ed25519 v2 signed blob, same baked-in public key. v3 binding is not in this release.
- Pre-existing online activation flow.

## Stable channel

This release supersedes v0.15.6 on the stable channel. Beta channel users on the v0.15.x line will see 0.16.0 as the next available update. If you have been running a beta and want to stay on stable from now on, switch the channel in Settings, Updates after upgrading.

## If you hit a problem

`%APPDATA%\Utterbar\logs\` has the app log. `crash.log` has any panic traces. Every meeting and dictation log line carries provider telemetry, useful for "did GPU acceleration run on this attempt?". If GPU paths crash, switch Settings, Advanced, GPU acceleration to CPU and email hello@ddraig.dev with the log file.
