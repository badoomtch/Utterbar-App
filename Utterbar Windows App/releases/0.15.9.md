# Utterbar 0.15.9 (beta)

A small reliability fix on top of v0.15.8: file transcription now uses the same output validator as regular dictation, so obvious ASR junk no longer ends up in the sidecar files next to your audio.

## What this fixes

When you drop an audio or video file in for transcription, Utterbar writes three sidecar files next to the source: `<name>.utterbar.txt`, `<name>.utterbar.srt`, and `<name>.utterbar.vtt`. Up to v0.15.8, if the recogniser produced obvious garbage (an empty string, a single period, a stuck loop like "the the the the the the", a long run of repeated punctuation, or text in a non-Latin script when the engine is pinned to English), those sidecars still landed on disk.

v0.15.9 catches the same set of cases v0.15.8 catches for regular dictation, but on the file-transcription path. If the transcript fails validation, no sidecar is written. The job is marked failed with a clear error message: "Output filtered. The transcript looked like ASR junk, so no sidecar files were written." Your source file is left alone.

## What changes

- File transcription runs the shared validator on the post-processed transcript before any sidecar write.
- On a filtered drop: no `.utterbar.txt`, no `.utterbar.srt`, no `.utterbar.vtt` are written.
- The job lands as Error with a single-line user-facing message so you can tell a filtered drop apart from a decode failure or an ASR error.
- One structured log line per drop in `%APPDATA%\Utterbar\logs\` carries the reason, model, language, duration, character count, and source path so support can see which rule fired without re-running the file.

## What this does not change

- Regular dictation validation from v0.15.8 is unchanged.
- Meeting Mode is unchanged. The shared validator is deliberately not applied to meeting transcripts.
- Engine-internal filters (the existing Whisper hallucination list and the Parakeet filler-word gate) stay where they are and run first, as before.
- Foreign-script filtering on the file path follows the same language rules as regular dictation: only fires when the engine is English-only or you have explicitly chosen English in Settings > Models > Whisper language. Whisper auto-detect and explicit non-English pins pass foreign script through unchanged.
- Pricing, licence system, updater, history persistence, the floating bar visuals.
- Local-only. No audio or transcript leaves your machine.

## Beta only

Beta-channel release. No `--announce`, no `latest` tag. Stable channel still serves v0.15.6.
