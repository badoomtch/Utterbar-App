# Utterbar 0.12.0

A larger-than-usual release. Five user-visible additions, plus a quiet but important piece of plumbing for IT teams who deploy Utterbar across a fleet.

This is the first mainline release on a new versioning convention: minor bumps (`0.x.0`) are mainline / stable, patch bumps (`0.x.y`) are beta soak. v0.11.0 and v0.11.1 were the beta soak for everything below; v0.12.0 is the mainline that ships them, plus the IT-deployment work and a small studio-brand change.

If you've been on the beta channel since 0.11.0, the new bits are the "For IT teams" section below and the support email in Settings → Licence. The rest is unchanged from 0.11.1.

If you've been on stable (0.10.0) and skipped the betas: this release brings everything 0.11.0 and 0.11.1 added, plus 0.12.0 on top. The full picture is below.

## Per-app auto-activation

Modes can now switch themselves on automatically based on which app you have focused. The rules editor in the mode editor was already there; this release wires the matcher to a foreground-window watcher.

- Match by executable name, window title, or window class. Wildcards (`*`) supported in all three.
- First match wins, scanning modes in the order they appear in your list. If two modes match an app, drag the one you want to win to the top.
- The watcher never switches modes mid-utterance. A queued switch waits for the next idle moment.
- The watcher polls roughly every 750ms — fast enough to feel responsive when you alt-tab, slow enough that the CPU cost is invisible.

Open Settings → Modes → edit a mode → "Auto-activation" to add rules.

## Subtitle export for file transcription

Every completed file-transcription job now writes `.srt` and `.vtt` sidecars next to the existing `.utterbar.txt`. So `meeting.mp4` becomes `meeting.utterbar.txt` + `meeting.utterbar.srt` + `meeting.utterbar.vtt`.

A note on timing: the underlying ASR wrapper drops per-word timestamps, so this release distributes total audio duration proportionally across sentence boundaries. **The timing is approximate at the sentence level.** Good enough as a rough pass to refine in Subtitle Edit, Premiere, Resolve, or whatever editor you use, but not word-perfect. The code is wired to switch to true word-level timing the moment a future engine populates real timestamps; nothing on the user side changes when that happens.

## History to vocabulary, in one click

The History detail modal now lets you fix mistranscriptions in place.

- Highlight a misheard word or phrase in either the Raw or Processed pane.
- "Add to vocabulary" stores it as a hinted word, so future ASR runs score it more highly.
- "Replace with…" creates a literal replacement rule: this came out, that's what I meant. Applied at post-processing time on every dictation.
- Either action triggers a one-click reprocess of the current entry, so you can see the fix take effect immediately.

No more copying a wrong word, opening Settings → Vocabulary, pasting it in, switching back. The whole loop happens inside the History modal.

## Better history filtering

The History page has filters for Mode (any of your modes), App (any executable that's appeared in your history), and a date-range chip group (All time / Today / 7 days / 30 days). All three combine with the existing search box; a "Reset filters" link appears when anything is set.

## For IT teams

Utterbar is now ready to be deployed across a managed fleet. A small set of behaviours can be pinned by an IT admin via the Windows registry under `HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Utterbar`, and they override the per-user setting on every read. Five values are pinnable today:

- `UpdateChannel` (REG_SZ: `stable` or `beta`)
- `CheckUpdatesAutomatically` (REG_DWORD: 0 or 1)
- `BlockModelDownloads` (REG_DWORD: 0 or 1) — refuses any new model download. Useful when models must come from an internal mirror.
- `BlockSystemAudio` (REG_DWORD: 0 or 1) — forces the capture source back to Microphone, disabling system / loopback audio capture for compliance.
- `RequireLicence` (REG_DWORD: 0 or 1) — refuses to dictate unless a Pro licence is active. Free tier becomes unavailable on managed devices.

Full deployment doc, including silent install, network egress, file locations, and air-gapped activation: <https://utterbar.com/docs/it-deployment>. New volume pricing on <https://utterbar.com/pricing>.

If you want a code-signed installer for a fleet rollout, mention it in the enquiry — we sign at order time and fold the cert cost into the quote.
