# Utterbar 0.7.4

A polish pass: a fast new way to add words to vocabulary from any app, an optional name-capture step in onboarding, and a clearer Free → Pro story on the Licence page.

## Vocabulary

- **Add words from any app via a global shortcut.** Bind an "Add to vocabulary" shortcut in Settings → Shortcuts. Select a word in any application, press the shortcut, confirm in the small quick-add window, done. Under the hood Utterbar synthesises Ctrl+C, reads the text from the clipboard, then puts your previous clipboard back. Plain-text clipboard only — image, file or rich-text clipboard contents are lost during capture (we restore plain text).
- **Quick-add window.** Tiny, focused, always-on-top. Esc closes, Enter saves. Selections longer than 60 characters or 5 words are rejected up front so the workflow stays for words and short phrases.
- **"Capture" button on the Vocabulary page.** Same workflow without leaving the page. Useful before you've bound a shortcut.

## Onboarding

- **Optional name capture on the final step.** "Want Utterbar to get your name right?" — type your name, hit Add, and the first dictation will spell it correctly. Skip is one click. The card hides itself once a name is added.

## Licence

- **Clearer Free → Pro explainer.** The Free state of Settings → Licence now lists the five things Pro actually unlocks: unlimited custom modes, unlimited vocabulary and replacements, file transcription, full history with re-transcribe, and the larger fp16 GPU model. With the matching Free cap quoted next to each — no marketing fluff.

## File transcription

- **Stronger first-impression copy.** Three concrete use cases (meeting recordings, podcast and video, voice memos) shown above the dropzone when there are no jobs in flight, so the feature reads as "this is what I'd actually use it for" rather than a generic upload box.
- **Clearer dropzone hint.** The dropzone now spells out where the result lands (`.utterbar.txt` next to the source file) so you don't have to guess.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
