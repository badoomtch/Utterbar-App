# Utterbar 0.9.0 (beta)

Security hardening pass. Mostly invisible to you, but the kind of work that matters before more people install this thing.

## Updates

- **Update metadata is now Ed25519-signed.** When the app checks for a new version, it verifies a signature over the response (version, channel, size, SHA-256, download URL) before downloading anything. A compromised server or someone in the middle can't push a malicious binary even if they could fake the JSON.
- **Refusal to downgrade.** If the update server ever offered a version that isn't strictly newer than the one you're running, the app now refuses to install it.
- **Download host pinned.** Updates are only ever pulled from `dl.utterbar.com`. Anything else is rejected on the client side.

## Licences

- **New live signing key.** The Ed25519 keypair that signs your licence has been rotated off the sandbox key that shipped with v0.6.x. The app accepts both the old key (so existing licences keep working straight after the update) and the new one. Future v0.9.x will sunset the old key once everyone is on a build that has the new one.
- **Cached licence is now encrypted at rest.** The fallback `licence.json` written to `%APPDATA%\Utterbar\` is wrapped with Windows DPAPI — only your user account on this PC can read it. Old plaintext caches are auto-upgraded on the next launch.

## Models

- **Every model in the catalogue now has a pinned SHA-256.** Downloads are verified against the hash before the file is moved into place. A model with a missing or wrong hash is refused, no silent install.
- **Whisper, Parakeet TDT, and Zipformer** all keep working as in 0.8.8 — no behavioural changes.

## Settings

- **Toggles look right again.** The on-state used to look like the knob was sitting on the very edge of the track because the active border was transparent. It isn't anymore.
- **Updates are all in one place.** "Check for updates automatically", "Update channel" (Stable/Beta), and "Check now" used to be split across General and Advanced. They're all in **Settings → General → Updates** now, in the order you'd actually use them.

## Site / billing

- **Tip-jar throttle tightened.** The Stripe checkout endpoint went from 30/min to 6/min per IP — still plenty for a real human, much less inviting for a botnet.
- **Admin API now keeps an audit log.** Every release-publish call records who tried, when, from where, and whether it succeeded.
- **Subscription confirm links are now POST-only.** Email pre-fetchers (Outlook, Gmail) can't accidentally confirm a subscription by following the GET link in the inbox preview.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
