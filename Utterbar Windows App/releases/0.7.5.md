# Utterbar 0.7.5

The auto-update flow now actually re-launches Utterbar after install, the update check is dialled back to once per app launch (not on every window focus), and the Toggle component has been retuned across the whole app.

## Auto-update

- **Utterbar now re-launches itself after a successful update.** Previously the app exited mid-install and you had to open it manually. The new build spawns a small detached Windows watcher before exiting that waits for the installer to finish, then starts Utterbar back up. No more "did the update work? where did the app go?".
- **One update check per app launch.** Previously Utterbar re-checked for updates whenever the main window got focus or whenever you opened Settings. That's overkill for an app that only ships every few weeks. Now it's a single check on launch (gated on the auto-update consent setting). Manually trigger a fresh check any time from Settings → General → "Check now".
- **"Updated to vX.Y.Z" toast.** First launch after an update now surfaces a small confirmation toast with a "See what's new" link to the changelog. Self-dismisses after twelve seconds.

## Settings

- **Toggle widget retuned.** The on/off switch was visually off — knob clipped against the right edge in the on state, aspect ratio was a touch stubby. Track is now 44×24 (modern platform default), knob travel is mirror-symmetric on both sides. Every toggle in the app uses the same component, so the fix applies everywhere.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
