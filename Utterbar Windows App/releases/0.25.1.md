# Utterbar 0.25.1 (beta)

A focused beta on top of v0.25.0. Stable users remain on v0.25.0.

## More reliable media pausing

This beta improves how Utterbar finds the active Windows media player when you start a microphone dictation. It is aimed at cases where YouTube, Spotify, or another player paused inconsistently.

With **Pause media while recording** turned on, playback should pause as dictation starts and resume when it ends. The setting and its behaviour are otherwise unchanged.

## What we need you to test

Please play a YouTube video, Spotify track, or another media source, then start and stop dictation several times. Try both a visible player and a browser tab in the background.

If playback still fails to pause or resume, send the log file from `%APPDATA%\Utterbar\logs\` to hello@ddraig.dev and include the player you used, whether it was in the foreground, and whether the failure is consistent or intermittent.

## What this does not change

- No speech recognition, model, audio capture, clipboard, or GPU behaviour changes.
- No settings layout or language changes.
- No updater, licence, purchase, activation, website, analytics, telemetry, or local LLM changes.
- No change to the experimental Teams and Discord microphone mute feature.
