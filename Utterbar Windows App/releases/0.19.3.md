# Utterbar 0.19.3 (beta)

A small beta hotfix on top of v0.19.2. Stable channel still serves v0.19.0.

## Read this first

This is a beta hotfix. Stable users remain on v0.19.0. v0.19.3 continues the same beta soak that v0.19.1 and v0.19.2 started, for the i18n + language-aware onboarding work, with one usability fix in Settings, Models. If you are on the beta channel, this is worth installing; if you dictate in English or use Auto-detect, nothing changes for you.

## What this release fixes

The warning v0.19.2 added to Settings, Models for non-English dictation language plus an English-only default model now appears directly beside the Whisper language picker, instead of further down the page. The previous placement, between the Default model card and the Meeting mode model card, made the warning easy to miss when you had just changed the Whisper language picker and were looking at that picker, not at the rest of the page.

- **The warning now sits immediately below the Whisper language card.** Change the Whisper language picker to a non-English language and the warning, if it applies to your selected default model, appears right under the picker that triggered it.
- **The switch-to-multilingual action is unchanged.** When the warning shows and you have a multilingual Whisper model installed, the "Switch to multilingual model" button still appears and still selects that model.
- **The no-multilingual-installed guidance is unchanged.** When the warning shows and no multilingual Whisper model is installed, the amber card still appears and still asks you to install one from the model list further down. Nothing is installed automatically.
- **Auto-detect and English still show no warning.** No new behaviour for users who keep Whisper language on Auto-detect or English.
- **Meeting mode model card still has no equivalent warning.** Every option in that picker is already a multilingual Whisper model, so a non-English dictation language is compatible with whichever Meeting mode option you choose.

## What this release does not change

- **The app interface is still English only.** No second language pack ships in this release. The dictation language picker controls only what Utterbar listens for, not what the app reads as.
- **Speech recognition behaviour is unchanged.** No change to Whisper, Parakeet, or Zipformer.
- **No speech model change.** No new model files, no model removals, no checksum changes for any installed model.
- **No audio capture change. No microphone routing change. No mic-mute change.**
- **No GPU acceleration change.** DirectML, CUDA, and CPU-only paths all behave as in v0.19.2.
- **No licence change. No Stripe change. No updater behaviour change. No website change. No analytics, no telemetry, no local LLM rewrite.**
- **No new outbound network calls from the desktop app.**
- **Stable users remain on v0.19.0** unless they opt into the beta channel from Settings, Updates.

## If you hit a problem

The app log is at `%APPDATA%\Utterbar\logs\`. If the warning shows when it should not, or fails to show when it should, please email hello@ddraig.dev with:

- the log file from `%APPDATA%\Utterbar\logs\`,
- the dictation language you have selected (Settings, Models, Whisper language),
- the default model you have selected (Settings, Models, Default model), and
- whether you have a multilingual Whisper model installed.

That last detail in particular helps us tell apart the "switch button missing when it should appear" case from the "install hint missing when it should appear" case.
