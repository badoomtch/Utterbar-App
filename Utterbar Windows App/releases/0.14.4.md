# Utterbar 0.14.4 (beta)

Three usability fixes from the v0.14.3 feedback. Beta channel.

## Meetings page refreshes by itself

Until now, finishing a meeting while you were already on the Meetings page meant the new entry didn't appear until you navigated away and back. The page only loaded on mount.

The page now subscribes to the same `dictation:result` event the rest of the app uses for "a transcript was just committed", filters on the meeting flag, and reloads the list. Stay on Meetings, finish a recording, the new card arrives without you doing anything.

## Delete a meeting from the list

Detail view's Delete button has been there since v0.14.0. The list view didn't have an obvious way to delete, so it wasn't clear meetings could be deleted at all. Each meeting card now has a small trash affordance in the top-right corner. It hides until you hover or focus the card so the list reads cleanly on first glance, then reveals when you're already looking at a row. Confirm dialog before delete, list refreshes automatically afterwards. Detail-view Delete still works the same way.

## Mode quick switch in the floating bar

The floating bar now shows up to five mode chips between the state pill and the action buttons in the non-listening expanded view. Each chip is the mode's icon. Click one to switch into that mode. The currently active mode is accent-tinted so you can see what's live at a glance.

Selection rule for which five modes appear:

1. Favourites first (in your sort order)
2. Built-ins next
3. Custom modes last
4. Capped at five

If you have more than five modes, the rest stay accessible from Settings → Modes. Switching while a recording is in progress is intentionally disabled because it would race the audio pipeline against an active capture; the chips only appear in the bar's idle and post-recording states.

Switching from one window now propagates to others. Setting the active mode anywhere (mode picker, bar, mode editor save) emits the standard settings-changed event, so the Modes page indicator and the bar's active highlight always agree.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log. `crash.log` has any panic traces. Send the newest files to `hello@ddraig.dev`.
