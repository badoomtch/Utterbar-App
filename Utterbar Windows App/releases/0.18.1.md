# Utterbar 0.18.1 (beta)

A small Settings beta on top of v0.18.0. Stable channel still serves v0.18.0.

## What this changes

The Settings search box in the sidebar now finds specific controls, not just broad section headings, and shows a small hint under each matching section telling you which control it is pointing you at:

- **Searches now match specific settings, not only section names.** Typing the name of a setting you remember will find it even if it lives inside a section you do not. Searching `smart rewrite` finds Text Output. Searching `apps to silence` finds Privacy. Searching `air gapped` finds Licence.
- **Common alternate phrasings work too.** You do not have to know the exact label of a control. `filler words` and `code dictation` both find Text Output (and the hint underneath says Smart rewrite). `teams mute` finds Privacy (and the hint says Mute conferencing app output).
- **A short hint appears under each matching Settings row while you are searching.** It tells you which one or two controls inside that section the search picked up. The hint disappears the moment you clear the search box, so the sidebar goes back to its normal look.
- **The About row's version line is unchanged when you are not searching.** It still shows the running version under About, the same as before. While searching, the version line on About is replaced by the matched-control hint, because that is what is useful in that moment.

Useful example searches to try:

- `smart rewrite` -> Text Output, hint Smart rewrite
- `filler words` -> Text Output, hint Smart rewrite
- `teams mute` -> Privacy, hint Mute conferencing app output
- `apps to silence` -> Privacy, hint Apps to silence
- `air gapped` -> Licence, hint Air-gapped activation
- `gpu` -> Advanced, hint GPU acceleration
- `launch startup` -> General, hint Launch at startup

## What this does not change

- **No website changes.** The marketing site is untouched.
- **No analytics, no telemetry.** Utterbar still sends nothing about your usage to us. The Settings search is purely local to your install.
- **No local LLM rewrite.** Smart rewrite stays the same deterministic rule-based feature it has been since v0.16.4. Search just helps you find the existing toggle faster.
- **No true per-app microphone mute.** The conferencing-mute control surfaced by search is the same v0.17.0 output-audio mute. Utterbar still does not mute your microphone inside Teams, Discord, Zoom, or Webex; use those apps' own mute buttons for that.
- **No changes to speech recognition, audio capture, microphone routing, GPU acceleration, the speech models, or the speech engine.** This release is a sidebar usability change only.
