# Utterbar 0.7.1

A focused follow-up to v0.7.0: the onboarding flow now scales to any window size, only shows the model that makes sense for a fresh install, and the trigger-style copy actually explains what each option does. Settings → Models also gains a "keep model loaded forever" option so you don't have to wait for a cold start ever again.

## Onboarding

- **The window scrolls and resizes properly.** On smaller monitors the Next button could fall off the bottom of the screen with no way to reach it. The onboarding window is now resizable, and the content area scrolls when the window is short.
- **Only the right model is offered to fresh users.** The picker now shows only the standard Parakeet v3 (English, compact) and "Skip — choose later". The Pro fp16 model and the older v2 build are no longer surfaced during first-run; they're still available from Settings → Models.
- **Trigger-style step actually explains itself.** Toggle, Hold-to-talk, and Push-to-talk now each have copy that distinguishes them. Previously Toggle and Push-to-talk read identically.

## Settings → Models

- **"Keep model loaded forever" toggle.** Replaces having to dial the unload timer up to ten minutes manually. Flip it on and the model stays warm for the whole session — every dictation is instant, no cold start. Off keeps the existing 1–600 second slider behaviour.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
