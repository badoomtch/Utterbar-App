# Utterbar 0.7.7

Two real fixes from the v0.7.6 install: the auto-update relaunch is properly silent now, and file transcription works.

## Fixed

- **Auto-update no longer flashes a command window.** The post-install relaunch watcher used to pop up a console window with a Windows error ("cannot find '\\\\'") because the running exe path included the `\\?\` UNC prefix and the relaunch script flags conflicted on Windows 11. Both issues are sorted: the prefix is stripped, the launch flags are corrected, and the relaunch is fully background.
- **File transcription accepts dropped and picked files again.** Drag-and-drop and the click-to-choose flow both used the HTML5 file API, which inside a Tauri webview doesn't expose real filesystem paths — the Rust side received "test.wav" and failed to open it. Both flows now use Tauri's native APIs and pass absolute paths.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
