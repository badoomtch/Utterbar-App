# Utterbar 0.7.2

A targeted fix for a scrolling regression that affected Settings and the first-run Onboarding window.

## Fixed

- **Scroll containers reach the true bottom of content.** On shorter windows the right-hand scrollbar in Settings (and the step pane in Onboarding) was bottoming out before the page actually ended — the last card or the Continue button could sit just below the visible area with no way to reach them. Both shells now derive their height from the document root rather than `100vh`, so the inner scroller always sees the real viewport.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
