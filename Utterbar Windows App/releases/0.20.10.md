# Utterbar 0.20.10 (beta)

A beta release that reworks Meeting Mode so the transcript shows who said what, adds a new English model, and tidies the model list and the graphics options. Stable users remain on v0.20.0.

## Read this first

This is a beta release. Stable users stay on v0.20.0 unless they opt into the beta channel from Settings, Updates.

## Meeting Mode now shows who said what

When you record a meeting, Utterbar now transcribes your microphone and the other people (the system audio) as two separate sides and labels them, so the transcript reads as a back-and-forth with speakers marked. You can rename the speakers afterwards on the Meetings page.

It also handles quiet stretches much better. Before, when one side went quiet while the other person talked, the app could invent text that was never said, sometimes in the wrong language. It now only transcribes the parts where someone is actually speaking on each side, so silence stays silent.

For the cleanest result, wear headphones. If you use speakers, your microphone also picks up the other people coming out of them, which can double up their words in the transcript.

If only one side is captured (just your microphone, or just system audio), the transcript works as before, without speaker labels.

## What this release adds

**A new English model: Parakeet v2.** It is fast on any modern computer and tuned purely for English. In everyday dictation it is very close to Parakeet v3, and it scored at the top of the open speech-recognition benchmarks when it was released. Pick it if you dictate in English only and want to try it. Install it from Settings, Models. It is free, like Parakeet v3, and Parakeet v3 stays the recommended default.

## What this release removes

**Whisper Turbo has been removed from the model list.** The list was getting crowded and Whisper Turbo overlapped with the models around it. Whisper base, small, medium, and large v3 still cover multilingual dictation, and Parakeet covers fast English. If you already installed Whisper Turbo, nothing on your machine is deleted, but it no longer appears as a new download.

## What this release changes

**The graphics acceleration options are tidier.** Settings, Advanced used to list a CUDA option. Utterbar has never actually used CUDA. It uses DirectML, which works on any modern graphics card, so picking CUDA quietly ran on your processor instead of your graphics card. The CUDA option is now gone. The choices are Auto (recommended), DirectML, and CPU only. If you had CUDA selected, Utterbar now uses the recommended Auto setting.

## What this release does not change

- **No change to everyday dictation.** Single-shot dictation, your text settings, and every model behave as before. The Meeting Mode changes only apply when a mode is flagged as a Meeting.
- **No change to the App language picker, no translation changes, and no new interface languages.**
- **No change to the auto-update flow, the experimental Teams and Discord microphone mute, the licence system, or Stripe.**
- **No new outbound network calls from the app** beyond downloading a model when you choose to install one.
- **Stable users remain on v0.20.0** unless they opt into the beta channel from Settings, Updates.

## If you hit a problem

The app log is at `%APPDATA%\Utterbar\logs\`. Email hello@ddraig.dev with the log file and a short description.
