# Utterbar 0.10.0

A small, focused release. Internal cleanup, no new user-facing features.

## Under the hood

- **Tighter licence verification.** The verifier now accepts only the live signing key family, dropping a transitional code path that was kept open during the v0.9.0 rollout. If you upgraded to v0.9.0 at any point your licence is already on the right footing and you'll see no change. If you somehow skipped v0.9.0 entirely, paste your licence key in once when prompted. The app will pull a fresh signed copy from the server.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
