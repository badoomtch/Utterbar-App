# Utterbar 0.26.0

This release moves Utterbar's downloads and in-app updates to GitHub Releases
as part of making the project open source.

## What changed

- Stable and beta updates now come directly from the official Utterbar GitHub
  repository.
- Downloaded installers are checked against the file size and SHA-256 digest
  published by GitHub before they are opened.
- Stable users receive normal GitHub Releases. Beta users can also receive
  prereleases.
- The website's Download and Changelog links now lead to GitHub Releases.

## One manual update is required

Versions before 0.26.0 only know the retired website update service. They
cannot discover this GitHub-backed release automatically.

Install 0.26.0 once from the official GitHub Releases page. Future stable and
beta updates will then work through the app again.

Your settings, models, history, vocabulary, and local data are preserved when
you install over an existing version.

## What did not change

- Speech recognition, audio capture, model selection, and GPU behaviour are
  unchanged.
- Utterbar remains local-first and does not add telemetry or cloud
  transcription.
- The experimental Teams and Discord microphone-mute feature remains included
  in the release build.

Report problems through the GitHub issue tracker and include your Utterbar
version, Windows version, and the steps that reproduce the problem.
