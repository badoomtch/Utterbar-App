# Utterbar 0.8

The 0.8 series. A meaningful step up from 0.7: real multi-engine support, file transcription that actually shows you the result, batch processing, and an auto-updater that finally lives up to its name.

## Multi-engine speech recognition

Three model families, all running locally on your PC. Pick whichever fits.

- **Parakeet v3 (English, compact)** — recommended default. Fast on any modern CPU, accurate on conversational English. ~460 MB.
- **Whisper base (multilingual)** — free tier. Around 99 languages with quality varying by language. Slower than Parakeet on English; comparable on non-English. ~200 MB.
- **Whisper small (multilingual, high accuracy)** — Pro tier. Bigger Whisper checkpoint, stronger non-English transcription. ~610 MB.
- **Zipformer (English, lightweight)** — free tier. Smaller download than Parakeet, faster cold start, accuracy a notch lower. Pick this on lower-spec PCs or when you want the lightest possible footprint.

Whisper has its own language picker in Settings → Models. Auto-detect is the default; pin a specific language for a small speed gain. Parakeet v2 retired — its files are cleared from disk on first launch, the migration moves you to v3 automatically.

## File transcription

- **Drop a folder, walk away.** Recursive walk, supported extensions only, up to 1,000 files queued in one go. Works for drag-and-drop and via the new "Pick a folder" button.
- **Click any finished job** to read the transcript in a modal. Copy to clipboard, show in folder, or delete (row only or row + the .txt file).
- **Inline row delete** for any non-running job. Errored / cancelled jobs can finally be cleared from the list.
- **"Queued N files" feedback** when a drop or folder enqueue lands.

## Text output

- **Numbers as digits** toggle in Settings → Text output (on by default). Converts spoken numbers to digits — "twenty three" → "23", "five pounds" → "5 pounds" — while leaving idioms intact ("one of these days" stays as words).

## Auto-update

- **Silent install + automatic relaunch.** When you click Install & restart on the update toast, the new version installs in the background and Utterbar reopens itself when it's done. No console window flash, no manual launch.
- **"Updated to vX.Y.Z" toast** on first launch after an update.

## Settings + onboarding

- Onboarding model picker filters down to the three free options users care about on first run; the multilingual nudge banner makes the Whisper option discoverable for non-English users.
- Settings → Models shows engine label per row (Parakeet · NVIDIA, Whisper · OpenAI, Zipformer · k2-fsa).
- Toggle widget retuned: knob travel is now mirror-symmetric, no more clipping in the on state.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
