# Utterbar 0.19.2 (beta)

A small beta hotfix on top of v0.19.1. Stable channel still serves v0.19.0.

## Read this first

This is a beta hotfix. Stable users remain on v0.19.0. It fixes a guidance gap in Settings, Models for non-English dictation language choices that landed on the v0.19.1 beta. If you are on the beta channel and you dictate in a non-English language, this is worth installing; if you dictate in English or use Auto-detect, nothing changes for you.

## What this release fixes

The v0.19.1 beta added a dictation-language step to onboarding. If you walked through onboarding and picked a non-English dictation language, the model step recommended a multilingual Whisper model and warned you if your selection was English-only. That warning was not yet visible on Settings, Models. So if you came back later, changed your dictation language in Settings, Whisper language and your default model was still English-only, nothing told you the two were now incompatible.

This release closes that gap.

- **Settings, Models now warns when your dictation language is non-English but your default model is English-only.** A small rose-tinted card appears between the Default model card and the Meeting mode model card explaining the situation in the same words onboarding uses.
- **If a compatible multilingual model is already installed, the warning offers a switch button.** Click "Switch to multilingual model" and your default model is set to the installed multilingual model the recommendation chooses.
- **If no multilingual model is installed, the warning explains that you need to install one from the model list.** No automatic install happens. The existing per-row Install buttons in the model list below are still the only place a download starts.
- **Auto-detect and English choices behave as before.** No new warning. No new card. The Default model picker, the Whisper language picker, and the Meeting mode model picker all behave exactly as they did on v0.19.1.

Meeting mode does not show the same warning because every option in its picker is already a multilingual Whisper model, so a non-English dictation language is compatible with whichever option you choose.

## What this release does not change

- **App interface is still English only.** No non-English UI language pack ships in this release. The dictation-language step controls only what Utterbar listens for, not what the app reads as.
- **No speech recognition engine change.** No change to Whisper, Parakeet, or Zipformer.
- **No speech model change.** No new model files, no model removals, no checksum changes for any installed model.
- **No audio capture change.** No microphone routing change. No mic-mute change.
- **No GPU acceleration change.** DirectML, CUDA, and CPU-only paths all behave as in v0.19.1.
- **No licence change. No Stripe change. No updater behaviour change. No website change. No analytics, no telemetry, no local LLM rewrite.**
- **No new outbound network calls from the desktop app.**

## If you hit a problem

The app log is at `%APPDATA%\Utterbar\logs\`. If the new warning misbehaves, please email hello@ddraig.dev with:

- the log file from `%APPDATA%\Utterbar\logs\`,
- the dictation language you have selected (Settings, Models, Whisper language),
- the default model you have selected (Settings, Models, Default model), and
- whether you have a multilingual Whisper model installed.

That last detail in particular helps us tell apart the "switch button missing when it should appear" case from the "install hint missing when it should appear" case.
