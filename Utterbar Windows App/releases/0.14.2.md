# Utterbar 0.14.2 (beta)

Whisper Large v3 stays in the catalogue, and now actually works. Plus housekeeping. Beta channel.

## The Whisper Large v3 crash, fixed

Anyone who installed Whisper Large v3 in v0.14.1 and tried to use it found the app crashed about 30 seconds into the first transcribe call, regardless of audio length. The cause was a language-sentinel mismatch.

Sherpa-onnx's `WhisperConfig.language` field expects either an empty string (auto-detect via the language-id tokens at decode time) or a concrete ISO-639-1 code such as `en` or `fr`. The literal sentinel `auto` is a UI/storage convention on Utterbar's side. Until v0.14.2, we passed `auto` straight through to sherpa.

Whisper base and small tolerated the unknown sentinel because their tokenizer's language-id set is small and the decoder fell back to auto. Whisper Large v3 doesn't. Its tokenizer hits an out-of-vocabulary lookup on the unknown language code, the resulting C++ exception unwinds through the FFI boundary, and the process exits hard.

Fix: map `auto` (and any unknown language values, for safety) to `""` before handing to sherpa. The persisted setting still says `auto` so the language picker UI keeps showing the right chip. Whisper Large v3 now runs to completion.

## Offline Zipformer retired

Removed from the catalogue. Parakeet covers the English fast-path comprehensively. Shipping two English-only fast models was creating decision fatigue in the model picker.

If you had Zipformer installed, this release prunes the catalogue row, nulls any modes that pointed at it, and removes the on-disk model directory. Same shape as the v0.8.0 Parakeet v2 cleanup. Zipformer's tarball stays available in k2-fsa's release archive if anyone wants it back.

If your global default model was Zipformer, the dictation path will now surface the standard "no model installed" prompt and you pick Parakeet (or Whisper) from Settings → Models.

## Release email subscription moved to Updates

The "Release updates" card lived in General Settings. It belongs with the rest of the version-management surface. Now lives on Settings → Updates alongside the channel selector, auto-check toggle, check-now button, and current-version release notes.

General Settings is now purely about theme, accent, sound profile, and notifications.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log. `crash.log` has any panic traces. Send the newest files to `hello@ddraig.dev`.
