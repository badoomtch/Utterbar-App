# Utterbar 0.6.3

The stability-plus-polish release. Fixes the crashes from 0.6.1, rewrites the History page, and cleans up a handful of UI annoyances.

## Fixed — stability

- **Crashes on repeated dictation.** A single hotkey press was silently invoking the start-recording command multiple times under the hood, which then raced three microphone streams and a native model-build in parallel and reliably corrupted the app's memory. Crashes could happen within a few minutes of use on 0.6.1. One press now means one recording, full stop.
- **Crashes 30–60 seconds after use.** A second crash class that survived the fix above — the idle-unload sweeper was dropping the native speech recogniser while another dictation was still holding a reference to it, racing the native C++ teardown. The sweeper now refuses to unload while any dictation is still in flight.
- **New recordings can't start while the previous is still transcribing.** Before now you could tap the hotkey mid-transcribe and start a second recording, which raced the first one through the inference engine. You now get a quick accent-border flash on the floating bar as a "noted, wait a second" cue, and the next press once transcribe finishes starts cleanly.
- **The start / stop cue played up to six times per press.** Same underlying cause as the first crash. Gone.
- **Hotkey silently stops working.** If an earlier recording didn't close down cleanly, subsequent hotkey presses would do nothing until you restarted the app. There's now a self-heal: if the recording or transcribe guard is stuck for longer than it should be with nothing actually running, the app recognises the stale state and starts the new recording anyway.
- **Transcription making up filler words.** If you tapped the hotkey by accident or stopped too early, the transcriber would sometimes insert a phantom "yeah" / "so" / "mm" / "uh" from the room tone. Those are now caught and dropped before anything reaches your clipboard.

## Fixed — UI

- **History page redesigned.** One full-width column of entries instead of a cramped two-column split that squeezed the list to ~200 px on normal window sizes. Click any entry to open the detail — raw transcript, processed output, reprocess-as-mode, context inspection — in a modal. Works at any window size, dismisses with Escape.
- **Floating bar opens and closes in one smooth motion.** Width, icon opacity, and icon position now finish their animations within a single 280 ms window instead of three separate springs ending at different times. No more staggered stages on hover-in, hover-out, record start, or record stop.
- **Floating bar border lights up cyan while you drag it.** The whole pill perimeter now glows the accent colour for the duration of the drag. Visible the instant you click-and-hold.
- **Floating bar collapsed state fits its content.** The closed pill used to float the logo + "Utterbar" wordmark inside a wide expanse of empty gradient; now it hugs tight.
- **Floating bar expanded state has no dead gap.** The recording indicator + timer + waveform now sit directly next to the wordmark instead of being pushed to the far right with empty pill between.
- **Main window scrollbars cleaned up.** At most one scrollbar per column at any window size — previously a third bar could appear on narrow widths, scrolling the left menu from the wrong place. Sidebar footer stays visible on short windows too.
- **Floating bar icons ease out smoothly when you move off.** Before they just popped out of existence.
- **In-app Pro price fallback** corrected from $29 to £39.99 on first launch before the real price arrives from the server.
- **Free-tier "Full history is Pro" message fits on screen** — now a clear full-width card above the list rather than a cramped half-width nag that wrapped one word per line.
