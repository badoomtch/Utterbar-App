# Utterbar 0.20.5 (beta)

A beta release on top of v0.20.4 that fixes long dictations being cut short, adds a self-repair for a damaged history file, and tidies up a few smaller things. Stable users remain on v0.20.0.

## Read this first

This is a beta release. Stable users stay on v0.20.0 unless they opt into the beta channel from Settings, Updates. If you are already on the beta channel (v0.20.4), this update is worth taking for the long-dictation fix alone.

## What this release fixes

**Long dictations no longer lose everything after the first 30 seconds.** If you use one of the Whisper models and speak for longer than about half a minute in a single dictation, earlier versions kept only the first 30 seconds or so and silently dropped the rest, with no error and nothing to tell you it had happened. v0.20.5 transcribes the whole recording in order and stitches it together, however long you speak, up to the existing five-minute single-dictation limit. Meeting Mode already worked this way; now normal dictation does too. The Parakeet model was never affected by this.

**Two numbers spoken in a row are no longer merged into one.** Saying "twenty thirty" used to come out as "50", and "five six" as "11". Now Utterbar only combines number words that genuinely form a single number: "twenty three" is still "23", but "twenty thirty" stays "20 30" and "five six" stays as two separate numbers.

**Utterbar repairs its history file instead of refusing to start.** If the file that stores your dictation history ever became damaged, for example after copying your profile across from another machine or an unclean shutdown, earlier versions could fail to start at all and lock you out of the app. v0.20.5 checks that file when it starts, sets a damaged one aside, and restores your most recent good backup. If no backup can be used it starts with a fresh history rather than failing to open. Your settings and your licence are stored separately and were never at risk.

**Utterbar keeps listening a moment longer after you stop.** People reported the last word of a sentence being clipped on natural endings. Utterbar now keeps capturing for a short beat after you release the hotkey, so trailing words land in the transcript. In practice the recording takes a fraction of a second longer to stop than it used to. That is deliberate.

**Your previous clipboard comes back sooner.** v0.20.4 already stopped Utterbar pasting the wrong (previous) clipboard contents after a dictation. v0.20.5 hands your previous clipboard back to you faster once the focused app has taken the dictated text, so there is a shorter window where a manual paste would still give you the dictation.

**Some settings descriptions were showing raw codes.** A few descriptions in Settings displayed things like `&lsquo;` and `&rarr;` instead of quotation marks and arrows. They now read correctly, and the interface wording has had a light tidy-up.

## What this release does not change

- **The five-minute single-dictation limit still applies.** The long-audio fix transcribes the whole recording up to that limit; it does not remove the limit. Longer sessions still belong in Meeting Mode.
- **No new models, and no change to the Parakeet or Zipformer models.** No model files were added, removed, or changed. Only the way long recordings are handed to the Whisper models changed.
- **No change to the App language picker, no translation changes, and no new interface languages.** The interface is still English. The Spanish, French, German, Italian, Portuguese, and Dutch translation review is unchanged.
- **No GPU acceleration change.** DirectML, CUDA, and CPU paths behave as before.
- **No change to the auto-update flow, the experimental Teams and Discord microphone mute, the licence system, or Stripe.**
- **No new outbound network calls from the app.**
- **Stable users remain on v0.20.0** unless they opt into the beta channel from Settings, Updates.

## If you hit a problem

The app log is at `%APPDATA%\Utterbar\logs\`. If something looks wrong, email hello@ddraig.dev with the log file, which app you were dictating into, and a short example of what you said and what appeared.
