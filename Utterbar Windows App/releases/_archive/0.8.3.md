# Utterbar 0.8.3

Smarter auto-update relaunch — should now actually reopen Utterbar after install completes, even on slower PCs and in the presence of Defender SmartScreen.

## Auto-update

- **Watcher waits for the binary to actually be ready, then retries.** v0.8.1 / v0.8.2 used a fixed 8-second sleep before relaunching the app. That worked when the installer finished within 8 seconds AND nothing intervened. On slower PCs and on machines with strict Defender / SmartScreen, neither was guaranteed. The watcher now polls the freshly-installed exe's mtime; once it's been unchanged for 3 seconds (so NSIS is genuinely done), it tries to launch up to 5 times with a 1-second gap. If a launch still fails after the retries, the user can open Utterbar from the Start Menu shortcut as a fallback. Hard-capped at 60 seconds total wait.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
