# Utterbar 0.8.0

The first 0.8.x release. Big internal restructure: the inference layer now dispatches on engine kind, so multilingual (Whisper) and faster English (Zipformer) can land in 0.8.1 and 0.8.2 without further plumbing. Plus a stack of file-transcription, settings and model-catalogue improvements that have been staging since 0.7.8.

## Models

- **Parakeet v2 retired.** Both `v2-int8` and `v2-fp16` removed from the catalogue. If you had v2 set as your default model, settings and modes are migrated transparently to v3 on first launch — your existing v2 files are left on disk but the catalogue stops listing them. No re-download required: Parakeet v3 int8 is the same size class.
- **Parakeet v3 fp16 added** (Pro). Higher-precision weights of the v3 architecture. Better accuracy on accents, proper nouns and noisy audio. Requires a supported GPU; CPU-only Settings → Advanced will refuse to load it.
- **Engine label on every model** in Settings → Models so you can see at a glance which family a model is from.

## Files

- **Drop a folder, walk away.** Drag-and-drop now accepts folders — recursive walk, supported extensions only, up to 1,000 files per drop. The same flow is available via "Pick a folder instead" below the dropzone.
- **Click any finished job to read the transcript.** Transcript modal shows the full text with **Copy**, **Show in folder**, and **Delete** (row-only or row + .txt file).
- **Inline row delete** for any non-running row. Errored / cancelled jobs can finally be cleared from the list without opening anything.
- **"Queued N files" feedback** when a drop or folder enqueue lands.

## Text output

- **Numbers as digits** toggle (Settings → Text output, on by default). Converts spoken numbers to digits — "twenty three" → "23", "five pounds" → "5 pounds" — while leaving idioms intact ("one of these days" stays as words). Turn off if you prefer numbers spelled out.

## Updater

- **Auto-update relaunch is silent now.** Earlier 0.7.x releases would flash a command window with a `'\\'` error and fail to relaunch. The relaunch watcher strips Windows UNC prefixes from the exe path and uses corrected creation flags so the upgrade is fully background.

## Roadmap

- **v0.8.1**: Whisper engine wired in. Multilingual support (~99 languages), language picker on Whisper models, onboarding picker gets a multilingual option.
- **v0.8.2**: Zipformer engine wired in. Faster English, smaller download.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
