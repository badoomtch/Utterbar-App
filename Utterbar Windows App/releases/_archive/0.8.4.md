# Utterbar 0.8.4

The third recogniser engine lands. Plus a small onboarding nudge for non-English users.

## Models

- **Zipformer (English, lightweight)** added to the Free tier. ~220 MB — smaller than Parakeet, faster cold start. Accuracy a notch below Parakeet on conversational English; the trade is "smallest footprint, lowest-spec PCs friendly". Pick this from Settings → Models if you want the lightest possible setup or if Parakeet feels heavy on your hardware.
- All three engine families (Parakeet, Whisper, Zipformer) now live behind the same dispatch layer — the inference orchestrator picks the right recogniser at load time based on the model's engine field.

## Onboarding

- **Multilingual nudge** on the model picker step: a single line above the model list reminding users dictating in non-English to pick the Whisper option below. Doesn't change the recommendation, doesn't add a step — just makes the multilingual path discoverable up front.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
