# Utterbar 0.8.1

Two real fixes from v0.8.0. If you saw the `\\` error pop up after clicking Install, or had to manually pick a new model, this release sorts both.

## Fixed

- **Auto-update relaunch is genuinely silent now.** v0.7.5 through v0.8.0 tried to use a `cmd /c` watcher to relaunch Utterbar after the installer finished — it kept tripping over Windows path quirks and showing a `'\\'` error window. The watcher is now a hidden PowerShell one-liner that takes the executable path as a typed argument (no string interpolation, no shell parsing), and the path is canonicalised to bypass NSIS junctions. Click Install & restart, the app exits, the new build installs, and Utterbar reopens itself.
- **Parakeet v2 retirement is properly cleaned up.** v0.8.0's migration nulled the default-model setting but left users staring at silent stub transcription with no obvious next step. Now: if you had v2 installed, the v2 files and DB rows are removed, and the app opens straight to **Settings → Models** on first launch so you can pick Parakeet v3 in two clicks. New installs are unaffected.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
