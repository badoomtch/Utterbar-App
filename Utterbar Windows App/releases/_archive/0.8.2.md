# Utterbar 0.8.2

Multilingual lands. Plus the auto-update relaunch is hardened against managed corporate Windows installs.

## Multilingual via Whisper

- **Whisper base (multilingual)** added to the Free tier. Around 99 languages, ~145 MB download. Pick this from Settings → Models if you dictate in anything other than English. Slower than Parakeet on English; comparable on non-English.
- **Whisper small (multilingual, high accuracy)** added to the Pro tier. ~480 MB. Stronger non-English accuracy than base. Worth it if you dictate frequently in a non-English language.
- **Language picker** appears on Settings → Models when a Whisper model is installed. Auto-detect is the default — Whisper detects the language at the start of each utterance. Pinning a specific language is slightly faster but loses the multilingual ability.

## Engine

- **Real Whisper recognizer** wired in via sherpa-onnx's `WhisperRecognizer`. Same DLL as Parakeet, different recogniser class. Same silence/duration gates (Whisper hallucinates harder than Parakeet on quiet input — the gates pre-reject anything the recogniser would confabulate on).

## Updater (more belt-and-braces)

- **PowerShell relaunch watcher** now passes `-ExecutionPolicy Bypass` so it survives managed corporate Windows installs where the policy is set to AllSigned or Restricted. The inline command payload doesn't load anything from disk so the policy bypass is purely a "let this one-liner run" gate, not a security relaxation.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
