# Utterbar 0.20.1 (beta)

A small beta on top of v0.20.0. Stable channel still serves v0.20.0.

## Read this first

This is a review beta for the first batch of non-English app interface languages. Stable users remain on v0.20.0. Pick up this beta if you want to try the new locales and tell us what reads awkwardly. If you only dictate in English and use the English UI, nothing in this release changes the experience for you.

## What this release adds

The first batch of non-English app interface languages is selectable in Settings, General, App language. The full picker now offers:

- English (default)
- Español
- Français
- Deutsch
- Italiano
- Português
- Nederlands

English remains the default. Switching to any of the other six languages re-renders the parts of Utterbar that are routed through the app text catalogue: the floating bar, the main-window sidebar and chrome, the update toast, onboarding, and most Settings panes (General, Text Output, Accessibility, Bar, About, Shortcuts, Audio, Privacy, Updates, Advanced, Models page header, Whisper-language card, language compatibility warnings).

The dictation language stays separate. It lives in Settings, Models, Whisper language, and is independent of the app interface language. Switching the app interface to Español does not change what Utterbar listens for; switching the dictation language to French does not change the app interface.

## Honest framing on translation quality

These translations are first-pass and need a native review pass before they reach the stable channel. They were generated as a single batch and aim for natural, neutral UI register, but a single non-native author cannot catch every awkward phrasing or regional preference. Expect to find:

- Sentences that are technically correct but sound slightly off in everyday use.
- Word choices that vary between regional preferences (for example European vs Brazilian Portuguese, or French software conventions).
- Container fits in German that occasionally feel tight.

If you spot something wrong, please email hello@ddraig.dev with: the locale, the screen, the current string, and the better wording you would prefer. We are gathering this feedback specifically to inform the native review pass before the next stable cut.

## What is intentionally still in English

Some surfaces in the app are not yet routed through the catalogue and continue to render in English regardless of which app language you pick. These include:

- The Licence settings page.
- The bulk of the Models page body (per-model descriptions, install state strings, file paths).
- The History, Files, Meetings, Modes, and Vocabulary pages.
- Backend messages: error envelopes, model display names, OS device names, file paths, server-returned subscription messages.
- Release notes (you are reading them in English right now).

This is by design for this review batch. Wiring those surfaces through the catalogue is separate, deferred work.

Right-to-left languages (Arabic, Hebrew) are also deliberately not in this batch. Adding RTL safely needs a layout pass that has not been done yet.

## What this release does not change

- **No speech recognition behaviour change.** No change to Whisper, Parakeet, or Zipformer. Transcripts on identical audio, model, and dictation language settings are byte-identical to v0.20.0.
- **No new speech models.** No model files added or removed, no checksum changes for any installed model.
- **No audio capture change. No microphone routing change.**
- **No GPU acceleration change.** DirectML, CUDA, and CPU-only paths all behave as on v0.20.0.
- **No change to the auto-update flow.** Install & restart still applies on the first click as v0.20.0 introduced.
- **No change to the experimental Teams and Discord microphone mute.** Same opt-in feature, same caveats, same off-by-default behaviour.
- **No licence change. No Stripe change. No purchase or activation flow change.** Same one-time £39.99 GBP, same three-device cap, same offline activation flow.
- **No new outbound network calls from the desktop app.** Same five outbound calls as v0.20.0.
- **No analytics, no telemetry, no local LLM rewrite.** Smart rewrite remains the deterministic rule-based pipeline.
- **Settings layout, hotkeys, and the floating bar's appearance are unchanged.**
- **Stable users remain on v0.20.0** unless they opt into the beta channel from Settings, Updates.

## If you hit a problem

The app log is at `%APPDATA%\Utterbar\logs\`. If something misbehaves after switching app language, please email hello@ddraig.dev with:

- the log file from `%APPDATA%\Utterbar\logs\`,
- the version reported in Settings, About,
- the app interface language you have selected (Settings, General, App language),
- the dictation language you have selected (Settings, Models, Whisper language),
- the screen where the issue happens, and
- whether the issue happens only on a specific app interface language or on all of them.

If the issue is a translation rather than a bug, the same address works for translation feedback; please include the locale, the screen, the current string, and your suggested replacement.
