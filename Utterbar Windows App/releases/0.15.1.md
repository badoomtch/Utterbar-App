# Utterbar 0.15.1 (beta hotfix)

Speaker diarisation **disabled** in Meeting Mode. Beta channel only.

## What this fixes

Real-meeting testing of v0.15.0 produced unusable output:

- A 5-minute meeting transcript labelled **91 different speakers** (over-fragmented clustering — every short utterance with slightly different acoustics became a new "speaker").
- Whisper Large hallucinated phrases in random languages (Hindi, Vietnamese, Japanese, Arabic) on short / noisy / music-only segments.
- Per-segment Whisper Large CPU calls made transcription take many minutes for a five-minute meeting.

These are architectural problems in the v0.15.0 diarisation design — they aren't tunable away by raising the clustering threshold. The fix needs a different shape entirely (transcribe once over the whole buffer, then assign speaker labels to the resulting timestamped text — see "What's coming in v0.15.2" below).

For v0.15.1 the right call is to **stop shipping the broken path** while the rework lands.

## What v0.15.1 does

- **Meeting Mode no longer attempts speaker diarisation.** Every meeting transcript is now produced by the bounded chunked path that was already the v0.15.0 fallback: 30-second chunks with 2-second overlap, timestamps every chunk, **no `**Speaker N:**` labels**.
- **No more ~47 MB diariser model download on first meeting.** v0.15.0 prefetched the pyannote + TitaNet pair when you started a meeting; v0.15.1 doesn't, because the stop side never uses them. First meeting on a fresh install is now instant — no model download wait, no progress toast, no first-meeting tax.
- The diariser code (asset download, sherpa wrapper, segment helpers) **stays in tree** — v0.15.2 will rework the architecture and reuse what still applies.
- Whisper Large is still required for meeting mode (the chunked path uses it). Same start-time refusal as v0.15.0 if you haven't installed it: *"Meeting mode needs Whisper Large. Install it from Settings → Models, then start the meeting again."*
- **Defence-in-depth chunk cap of about 60 minutes.** A single meeting longer than roughly one hour (60 minutes 40 seconds, to be exact) fails fast with a *"split into shorter recordings"* error rather than queuing dozens of sequential Whisper Large CPU calls and hanging the app for an hour-plus. The cap is sized to comfortably accept full 30 / 45 / 60 min meetings — the standard meeting cadence — with a small safety shoulder for "I forgot to stop". It's a deliberate beta limitation: Whisper Large on CPU runs at roughly real-time, so a one-hour meeting still takes about an hour to transcribe; anything longer should be split into separate recordings.
- New log lines on every meeting so the disabled state is visible in `%APPDATA%\Utterbar\logs\`:
  - on start: `meeting mode diarisation asset preflight disabled in v0.15.1 beta hotfix`
  - on stop: `meeting mode diarisation disabled in v0.15.1 beta hotfix; using chunked transcript without speaker labels`

## Workaround for cross-language Whisper hallucinations

Whisper's "auto" language detection is what produces foreign-language confabulations on quiet/ambiguous audio. Pinning a language at recogniser construction stops it cold:

1. Open **Settings → Models**.
2. Under **Whisper language**, change from *Auto-detect* to **English** (or whatever you're actually transcribing).
3. Restart the app (the language is set when Whisper loads).

This affects all Whisper transcription, not just meetings — useful for dictation too if you've ever seen `[Music]` or random foreign script in your output.

## What's the same

- Dictation mode (non-meeting): completely unchanged.
- Pricing (£39.99 GBP one-time Pro), licence, updater, history, modes, file transcription, floating bar — all untouched.
- v0.14.x meeting transcripts already in your history render exactly as they always did.
- The v0.15.0 concurrency hardening (start_recording_pending CAS-mutex, time-gated stale-heal, two-stage re-entry decision) stays — it's correct.

## What's coming in v0.15.2

The architectural rework that the v0.15.0 attempt taught us we needed:

- **One Whisper pass over the whole meeting buffer**, not N passes over N diariser segments. Eliminates the per-segment runtime explosion AND the short-clip hallucination problem (Whisper sees full context).
- **Speaker labels assigned post-transcription** by mapping diariser segments onto the transcript's word/sentence timestamps.
- **Hard cluster caps** so a noisy room can never produce 91 fake speakers.
- **VAD pre-filter** so music / silence / cross-talk slices never get fed to Whisper.

No date yet — the rework needs provider-level changes (per-call language hints, word timestamps from sherpa-rs Whisper) we haven't confirmed are available. v0.15.2 lands when it lands.

## Beta only

This is a beta-channel hotfix. Stable channel is intentionally unchanged. Speaker labels stay disabled until v0.15.2 ships and proves out on real meetings.
