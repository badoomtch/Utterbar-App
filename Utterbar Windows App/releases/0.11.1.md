# Utterbar 0.11.1 (beta)

A small follow-up to 0.11.0.

## Fixed

- **Filter dropdowns on the History page no longer clip option labels.** The Mode and App dropdowns were inheriting the trigger-button's narrow width, then truncating each option label to a single character. The dropdown panel now grows to fit its longest option, regardless of how narrow the trigger sits.

## Everything else

Same as 0.11.0. If you're already on 0.11.0 the only difference you'll notice is that "Voice to text" reads as "Voice to text" in the History → Mode dropdown, instead of "V…".

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
