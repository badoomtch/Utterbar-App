# Utterbar 0.19.4 (beta)

A small beta hotfix on top of v0.19.3. Stable channel still serves v0.19.0.

## Read this first

This is a beta hotfix. Stable users remain on v0.19.0. v0.19.4 continues the same beta soak that v0.19.1, v0.19.2, and v0.19.3 started, with one fix to the auto-update flow itself.

## What this release fixes

The Install & restart button on the in-app update toast now reliably applies the update on the first click. Previously, if you had Close to tray turned on (the default), clicking Install & restart would sometimes hide the app to the tray instead of installing the update. Reopening the app and clicking Install & restart again would then work, but a single click is what we want.

The cause was an interaction between two settings working as designed:

- The updater needs the running Utterbar to exit so the new version can overwrite it on disk.
- Close to tray treats every close request as "the user wants to keep the app running, just minimised", and intercepts it.

When the updater asked the app to exit, Close to tray treated that exit like a normal click on the X button and hid the window instead. The new installer never got to run, the running app stayed alive, and the update silently did not apply.

This release teaches Close to tray to recognise the updater's exit and let it through. Normal clicks on the X button still go to the tray exactly as before. Tray quit, normal startup, and normal shutdown are all unchanged.

A small bonus fix: the Install & restart button now ignores a fast double-click while it is in flight. The single-click path is the only path that does anything; a second click within the React render window is silently dropped instead of firing the install twice.

## What this release does not change

- **The app interface is still English only.** No second language pack ships in this release.
- **Speech recognition behaviour is unchanged.** No change to Whisper, Parakeet, or Zipformer.
- **No speech model change.** No new model files, no model removals, no checksum changes for any installed model.
- **No audio capture change. No microphone routing change. No mic-mute change.**
- **No GPU acceleration change.** DirectML, CUDA, and CPU-only paths all behave as in v0.19.3.
- **No licence change. No Stripe change. No website change. No analytics, no telemetry, no local LLM rewrite.**
- **No new outbound network calls from the desktop app.**
- **The Settings, Models language-compatibility warning is unchanged.** Same placement (beside the Whisper language picker), same one-click switch behaviour, same install hint when no multilingual model is installed.
- **Stable users remain on v0.19.0** unless they opt into the beta channel from Settings, Updates.

## If you hit a problem

The app log is at `%APPDATA%\Utterbar\logs\`. If Install & restart still does not apply on the first click, please email hello@ddraig.dev with:

- the log file from `%APPDATA%\Utterbar\logs\`,
- whether you have Close to tray turned on or off (Settings, General),
- whether the update was offered automatically on launch or after a manual Check now (Settings, Updates), and
- whether the app appeared to vanish to the tray, or simply stayed open with no installer running.
