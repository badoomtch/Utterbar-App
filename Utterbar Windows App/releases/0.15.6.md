# Utterbar 0.15.6

DirectML lands. Meeting Mode runs on the GPU on hardware that has one.

## What this fixes

Since v0.6, Utterbar's Settings → Advanced has had a "GPU acceleration" card with Auto / DirectML / CUDA / CPU radio buttons. Until v0.15.5 the card claimed running on the GPU was "3–10× faster than CPU" — but the shipping ONNX Runtime in every release back to v0.7.0 was CPU-only. v0.15.5 made the gap honest with a "Selected, but currently inactive" notice. v0.15.6 closes the gap: the runtime now actually does DirectML.

## What v0.15.6 changes

- **DirectML execution provider, embedded.** The vendored sherpa-onnx + ONNX Runtime DLL bundle at `Utterbar Windows App/src-tauri/vendor/sherpa-onnx/` has been rebuilt against `Microsoft.ML.OnnxRuntime.DirectML 1.14.1` and `Microsoft.AI.DirectML 1.15.0`. The runtime DLL set shipped to `%LOCALAPPDATA%\Utterbar\` (or wherever NSIS installs) gains `DirectML.dll` (~18.5 MB) and the DML execution provider is now exposed by `onnxruntime.dll`.
- **Whisper CPU-force lifted.** The v0.8.7 mitigation that hard-pinned every Whisper transcribe to CPU regardless of the user's GPU preference is gone. Step 2 smoke testing (8/8 cells PASS, no crashes) confirmed the original DirectML failure mode no longer reproduces against the new ORT 1.14.1 + DirectML 1.15.0 build. Whisper Small / Medium / Large v3 all run cleanly on the GPU now.
- **Model-aware Auto policy.** When the user picks Auto and a hardware GPU is present:
  - Whisper Medium → DirectML
  - Whisper Large v3 → DirectML
  - Parakeet TDT v3 int8 → DirectML
  - Whisper Small → **CPU**, because Step 2 30-second-clip evidence showed DML at 0.78× CPU for Small (overhead dominates short audio). Confirmed by real-meeting validation on Jay's machine pre-publish: Small CPU 5:43 meeting → RTF 0.190; Small DirectML 9:27 meeting → RTF 0.222 — the DML penalty for Small persists into long audio. Auto-Small stays on CPU.
- **Explicit DirectML still works for everything.** Picking DirectML in Settings → Advanced overrides the auto-Small CPU policy. If you specifically want Whisper Small on the GPU, set DirectML and it'll go.
- **Settings → Advanced no longer claims "GPU is active" when it isn't.** The honest copy added in v0.15.5 stays. The card now says what Auto actually does on this build, including the per-model nuance.
- **Provider telemetry gains two fields.** Every meeting and dictation log line now also carries `dml_available` (boolean — "is the runtime able to serve DML?") and `provider_policy_reason` (string — "why did the resolver pick this provider?"). Nine pinned reason strings: `user_explicit_cpu`, `user_explicit_directml`, `user_explicit_cuda`, `dml_ep_unavailable`, `cuda_ep_unavailable`, `auto_cpu_no_hardware_gpu`, `auto_cpu_no_dml_runtime`, `auto_small_prefers_cpu_short_clip`, `auto_dml_speedup`.

## What this does NOT change

- Your transcripts on CPU. Same audio in produces same text out as v0.15.5 when running on CPU.
- Your transcripts on DirectML are bit-identical to CPU on Whisper Medium and Large v3 (Step 2 evidence). Parakeet output may differ slightly because of GPU/CPU decoder-state non-determinism — both providers produce equivalent quality.
- Meeting Mode default (still Whisper Small from v0.15.4).
- The Meeting Mode allow-list (Small / Medium / Large v3 only).
- Pricing, licence system, updater, history, modes, file transcription, floating bar — all unchanged.
- Speaker diarisation is still disabled.

## Performance — what to expect

Two sets of measurements on Jay's machine. **Step 2 30-second clips:**

| Engine | CPU RTF | DML RTF | Speedup |
|---|---|---|---|
| Whisper Small | 0.143 | 0.183 | 0.78× (DML slower on short clips) |
| Whisper Medium | 0.362 | 0.200 | 1.81× |
| Whisper Large v3 | 0.734 | 0.267 | 2.75× |
| Parakeet TDT v3 int8 | 0.086 | 0.060 | 1.43× |

**Real-meeting validation:**
- Whisper Small CPU 5:43 meeting → RTF 0.190
- Whisper Small DirectML 9:27 meeting → RTF 0.222 (still slower than CPU even on long audio — that's why auto-Small stays on CPU)
- Whisper Medium DirectML 8:55 meeting → RTF 0.754 (vs the v0.15.4 CPU baseline of 0.87 on a different audio)
- Parakeet TDT v3 int8 CPU dictation → ran cleanly

Your hardware will land somewhere different. Speedup grows with model size — DML's per-session init overhead amortises across more compute on larger models.

### First-run cost on the GPU path

The first time DirectML uses a model in a session, the GPU has to compile the model graph for your hardware. This is a one-off cost paid lazily on the first dictation or meeting after launch:

- **Parakeet (dictation)** — roughly 20–25 s before the first transcript appears.
- **Whisper Medium / Large** — roughly 30–60 s on top of the transcribe itself for the first meeting; can stretch longer on the first chunk.

After that, the recogniser is cached for the session and subsequent dictations / meetings start instantly. Quitting the app loses the cache; the next launch pays the cold cost again on first use.

If a meeting feels stuck at "Warming…" or "Processing…" for the first minute, that's this — not a hang. Force-quitting cancels the work; let it finish.

## Hardware requirements

- Any **Direct3D 12 capable GPU**: NVIDIA GTX 10-series and newer, AMD RX 400/500-series and newer, Intel Arc, Intel integrated (UHD Graphics 600+), AMD integrated (Vega+).
- Windows 10 1903+ or Windows 11.
- If no DX12 GPU is detected, Auto runs on CPU.

## Installer size

The DirectML bundle adds ~18.5 MB of `DirectML.dll` plus a slightly larger `onnxruntime.dll` (DML build vs CPU build). Total runtime DLL footprint grows from ~14.9 MB to ~33.8 MB. NSIS LZMA compression brings the on-the-wire installer-size delta to roughly +12-15 MB.

## What's deferred

- **CUDA support.** DirectML covers all DX12 GPUs already. CUDA would be marginally faster on NVIDIA but requires a separate ~150 MB runtime; not worth the install-size cost.
- **Sentinel + post-mortem crash detection.** The v0.15.5 plan included a sentinel/quarantine path for native DML crashes. Step 2 produced zero crashes across 8 cells, so the defence-in-depth mechanism is deferred to a future release unless real soak data reveals a need.
- **Whisper Small DML default on Auto.** Currently CPU on Auto. If a future long-audio test reverses the 30-s-clip regression, Auto-Small will flip to DirectML.
- **Output validation that drops text** (foreign-script, empty). Designed-only since v0.15.5. Not blocking.

## If something goes wrong

`%APPDATA%\Utterbar\logs\` has the app log. `meeting transcribe complete` and `inference.transcribe done` lines now carry full provider telemetry — useful for diagnosing whether DML actually ran. If the GPU path crashes, switch to CPU in Settings → Advanced and email `hello@ddraig.dev` with the log file.
