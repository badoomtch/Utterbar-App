# Utterbar 0.21.2 (beta)

A clipboard hotfix on top of v0.21.1. Stable users remain on v0.21.0.

## What this fixes

Utterbar now restores copied images after dictation when clipboard restoration is enabled.

Previously, Utterbar remembered only copied text before it temporarily placed your transcript on the clipboard. If you had copied an image, the transcript paste replaced it and there was nothing available to restore afterwards.

This release preserves the normal Windows image formats used by copied screenshots, images from browsers, and common desktop applications, then restores them after the transcript has been pasted. It still leaves the clipboard alone if you or another app copy something new while Utterbar is waiting to restore it.

## What this release does not change

- **No change to transcript text insertion** beyond preserving copied image data for clipboard restoration.
- **No change to speech recognition, models, audio capture, Meeting Mode, or graphics acceleration.**
- **No change to the App language picker or interface translations.**
- **No change to the licence system, Stripe, price, or activation flow.**
- **No new outbound network calls, analytics, telemetry, or local LLM rewrite.**
- **Stable users remain on v0.21.0** unless they select the beta channel in Settings, Updates.

## Test this beta

Copy an image, dictate into a text field, then paste somewhere else after Utterbar finishes. The same image should still be available on the clipboard.

The app log is at `%APPDATA%\Utterbar\logs\`. If restoration still fails, email hello@ddraig.dev with the log file, the source of the copied image, and the app you dictated into.

Beta channel only. Stable channel still serves v0.21.0. No release announcement email and no `latest` tag.
