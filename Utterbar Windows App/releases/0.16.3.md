# Utterbar 0.16.3 (beta)

Desktop UX polish beta on top of 0.16.2. Stable channel still serves 0.16.0.

## What this changes

- **Updater relaunch now opens visibly.** Previously, after installing an update and letting Utterbar restart, the freshly-installed app could vanish into the tray if you had Settings, General, Start minimised to tray turned on. The Install button looked like it had failed. Now, after an update, the relaunched process opens the main window for that one launch so you can see the update has landed. Normal launch-at-login is unchanged: when you sign in to Windows the next morning, Utterbar still respects your start-minimised preference. Only the post-update relaunch overrides it.
- **Meeting Mode shows transcription progress.** Previously the floating bar sat on a static "Transcribing meeting…" pill for the entire chunked transcribe pass. For a five-minute meeting that is around 17 to 30 seconds with no feedback, which read as a hang on slower hardware. The bar now shows "Transcribing meeting · N/M" with a thin progress bar that fills as chunks complete. Progress is chunk-based, not word-level, and the counter updates roughly every 27 seconds of audio. Single-chunk meetings (under 30 seconds of audio) still show the bare "Transcribing meeting…" copy because there is nothing meaningful to plot.
- **Floating bar waveform now reacts to detected audio.** Previously the seven bars looped a constant decorative animation regardless of whether you were actually speaking, so the bar visually said "I'm listening" even during dead silence at the start of a recording. The bars now respond to live microphone level, settling to a flat row when you are silent and rising and falling with your voice when you speak. The level meter is computed locally from RMS and peak energy. It is not stored, and no audio is sent anywhere. Reduce motion in Settings, Accessibility still freezes the bars to a static row.
- **Settings sidebar has search.** A new search input above the Settings group filters the section list as you type. It matches by section name and a curated list of keywords per section: typing "GPU" finds Advanced, "hotkey" finds Shortcuts, "system audio" finds Audio, "ASR" or "whisper" finds Models, and so on. Empty search restores the full list. Esc clears the input. Search filters settings sections, not every individual control inside each section.

## What this does not change

- No changes to ASR models, the DirectML provider policy, or the runtime DLLs.
- No new settings, no new policy keys, no schema or licence changes.
- No website changes.

## Beta only

Beta channel only. No `--announce`. No `latest` tag. Stable channel still serves 0.16.0.
