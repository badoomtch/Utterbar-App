# Utterbar 0.20.7 (beta)

A beta release on top of v0.20.6 that fixes the push-to-talk and hold-to-talk hotkeys, makes the mode-cycle hotkey work, and adds an optional punctuation toggle. Stable users remain on v0.20.0.

## Read this first

This is a beta release. Stable users stay on v0.20.0 unless they opt into the beta channel from Settings, Updates.

## What this release fixes

**Push-to-talk and hold-to-talk now work.** If you bound "Push to talk" or "Hold to talk" in Settings, Shortcuts, pressing the key did nothing in earlier versions. Now holding the key records and releasing it stops, so you can dictate without the press-to-start, press-to-stop toggle. The default toggle hotkey (Ctrl+Space) still works as before.

**The mode-cycle hotkey now works.** "Cycle mode" in Settings, Shortcuts (default Ctrl+Alt+M) now switches to your next mode each time you press it. Earlier versions registered the key but did nothing with it.

## What this release adds

**Optional punctuation restoration.** Settings, Text Output has a new "Restore punctuation" toggle. When on, Utterbar adds punctuation to your dictation (commas, full stops, question marks) using a small on-device model. It is not an AI rewrite: it only adds punctuation, it never changes your words. It needs the "Punctuation restoration" model, which you can install from Settings, Models. It is off by default, and Meeting Mode is unaffected.

## What this release does not change

- **No change to transcription accuracy or your existing models.** Parakeet, and every Whisper model including Turbo, behave exactly as on v0.20.6.
- **No new outbound network calls from the app** beyond downloading a model when you choose to install one.
- **The punctuation toggle does nothing until you install its model.** If you turn it on without the model installed, your dictation is pasted exactly as before, with no error.
- **No change to the App language picker, no translation changes, and no new interface languages.** The interface is still English.
- **No change to the auto-update flow, the experimental Teams and Discord microphone mute, the licence system, or Stripe.**
- **Stable users remain on v0.20.0** unless they opt into the beta channel from Settings, Updates.

## If you hit a problem

The app log is at `%APPDATA%\Utterbar\logs\`. If a hotkey does not behave as expected, note which one and what happened, and email hello@ddraig.dev with the log file.

## Beta channel

Beta channel only. Stable channel still serves v0.20.0. No release announcement email, no "latest" tag.
