# Utterbar 0.16.5 (beta)

Small Settings and privacy-clarity beta on top of 0.16.4. Stable channel still serves 0.16.0.

## What this changes

The existing "mute conferencing apps while recording" toggle has had its scope made explicit, and you can now edit the list of apps it touches.

- **Clearer copy.** The toggle is now labelled "Mute conferencing app **output** while recording." It silences what you HEAR from Teams, Slack, Discord, Zoom, and Webex while you are dictating, so call audio and notification dings do not bleed into the room. The audio is restored the moment dictation ends.
- **The toggle does NOT mute your microphone inside those apps.** True per-app microphone mute would require simulating each app's in-call mute shortcut, which is brittle and out of scope. If you need to mute your mic to a call, use that app's own mute button.
- **Editable app list.** Settings, Privacy, Media now exposes "Apps to silence" under the toggle. By default it shows the built-in list (Teams.exe, ms-teams.exe, msteams.exe, slack.exe, Discord.exe, DiscordPTB.exe, DiscordCanary.exe, Zoom.exe, ZoomPhone.exe, webex.exe, WebexTeams.exe). Add or remove `.exe` names with the input field and chip buttons. Reset to defaults restores the built-in list. Names match running processes case-insensitively.
- **Validation.** The input rejects paths, drive letters, command lines, quotes, wildcards, and duplicates. Names auto-append `.exe` if you forget. Names over 64 characters are refused.

## Honest limits

- This release is **output-audio muting only**. Your microphone feed into Teams, Discord, Zoom, or Webex is unchanged. Use the call app's own mute button if you need that.
- Google Meet running in a browser tab is still out of scope. Browsers run audio through `chrome.exe` or `msedge.exe`, and adding those to the list would silence every browser tab while you dictate, which is rarely what anyone wants. If you knowingly accept that trade-off, you can add a browser executable yourself.
- Empty list still means "use the built-in defaults" at runtime. The main toggle remains the kill-switch for the whole feature.

## What this does not change

- No changes to audio capture, microphone routing, ASR runtime DLLs, model files, or the DirectML provider policy.
- No new policy keys, no schema changes, no licence or telemetry changes.
- No remote calls. The matching runs locally against the Windows audio session list.
- Meeting Mode and the history view are unaffected.

## Beta only

Beta channel only. No `--announce`. No `latest` tag. Stable channel still serves 0.16.0.
