# Utterbar 0.7.3

A pass on the auto-update flow. The toast now actually appears when a new version is detected, the manual "Check now" button is wired through the same UI, and onboarding asks you up front whether to enable update checks at all.

## Updates

- **Update toast appears as soon as a new version is detected.** Previously the check ran only at app launch and the toast wouldn't reappear until you toggled the auto-check setting off then on. Now the check re-runs every time the main window regains focus, every time you open Settings → General, and on launch. If a new version is out, the toast shows immediately.
- **"Check now" button now drives the toast.** Settings → General → "Check now" used to update the inline status but never raise the toast. Both surfaces now share state, so a manual click surfaces the install button right where you'd expect.
- **Onboarding asks for update-check consent.** A new step right after the privacy intro lets you choose whether Utterbar can call out to utterbar.com for version checks. Defaults to on, but the choice is explicit — and you can change it any time in Settings → General.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
