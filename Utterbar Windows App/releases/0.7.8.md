# Utterbar 0.7.8

File transcription now actually has an "after" — the bit you were missing.

## File transcription

- **Click a finished job to read the transcript.** Done rows are clickable; opens a modal with the full transcript text. Previously the only signal that a job had finished was a "Done" pill — the transcript file existed on disk but nothing in the app surfaced it. Now you can:
  - **Copy** the whole transcript to the clipboard with one click
  - **Show in folder** — opens Explorer with the .utterbar.txt file selected
  - **Delete** — drops the row from history; optionally also deletes the .txt file from disk (the source audio is never touched)
- **Esc closes the transcript view.** Standard modal behaviour.

## Notes

- The website previously claimed file transcription exported `.srt` and `.vtt` formats — that was incorrect, only `.txt` is produced today. The marketing copy is now honest about that. Subtitle formats are on the roadmap.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
