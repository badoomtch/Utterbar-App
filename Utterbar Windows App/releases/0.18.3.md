# Utterbar 0.18.3 (beta)

A diagnostic-only follow-up to v0.18.2. Stable channel still serves v0.18.0.

## What this changes

The experimental Teams + Discord microphone-mute toggles in v0.18.2 weren't muting Discord on at least one install (no banner appeared above the floating bar when the recording started, and the call app's mic icon never flipped). This release adds extra log lines on the mic-mute path so we can pinpoint where the path is dropping out, then ship a real fix in v0.18.4.

If you have one of the toggles on with a hotkey set and a call app open, just press your Utterbar recording hotkey once and let go. Then send us the lines from the app log starting with `mic_mute diag:`. The log file is at `%APPDATA%\Utterbar\logs\` and the lines tell us:

- whether the lifecycle hook even ran
- whether your audio source was Microphone (the only source the mic-mute path runs for)
- whether your toggle and hotkey were read correctly
- whether Utterbar found the Discord or Teams window on your machine
- whether the keystroke send returned Ok or an error

The log lines deliberately do NOT include your transcripts, your hotkey combo, your window titles, your clipboard, or any other secret. Only app names (`teams` / `discord`), outcomes (`Sent` / `NotRunning` / `SendFailed` / `NoHotkey`), and counts.

## What this does not change

- **No changes to the experimental feature itself.** The mic-mute apply path is still off by default. The hotkey synthesis is still the same one as v0.18.2; only the diagnostic log lines around it are new.
- **No analytics, no telemetry.** The new log lines are local to the same `%APPDATA%\Utterbar\logs\` file Utterbar already writes for everything else. Nothing is sent to us automatically; you have to send the file yourself.
- **No local LLM rewrite, no UI Automation mute verification, no OS capture-endpoint mute, no Zoom/Webex.**
- **No changes to speech recognition, audio capture, microphone routing, GPU acceleration, the speech models, or the speech engine.**
- **No website changes.**
