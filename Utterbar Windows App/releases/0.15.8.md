# Utterbar 0.15.8 (beta)

A small reliability fix on top of v0.15.7: regular dictation now filters obvious bad ASR output before it reaches your text or your history.

## What this fixes

The recogniser occasionally produces output that's clearly not what you said: a single period, a stuck loop like "the the the the the the", a long run of repeated punctuation, or text in a non-Latin script when the engine is pinned to English. Up to v0.15.7 these landed in your focused window and your history the same as a real dictation.

v0.15.8 catches them before insertion. The captured audio is dropped, no text is typed, and no successful history row is written. The floating bar shows "Output filtered" so you can tell a filtered drop apart from plain silence.

## What changes

- Regular dictation runs a shared validator on the post-processed transcript before text injection.
- Empty, whitespace-only, and single-punctuation outputs drop quietly with the existing "No audio detected" pill.
- Repeated-token loops, repeated-punctuation runs, and unexpected foreign-script output drop with the floating bar showing "Output filtered" in the same muted tone (non-error, non-alarming).
- Each filtered drop emits one structured log line (reason, model, language, duration, character count) so support can see which rule fired without reproducing the audio.

## What this does not change

- Meeting Mode is unaffected. Meeting transcripts can legitimately contain repetition or mixed-language content, so the new validator is bypassed there. The pre-existing empty-transcript guard still applies.
- File transcription is unaffected. The validator does not run on the .txt / .srt / .vtt sidecar path; that's a separate patch.
- Engine-internal filters (the existing Whisper hallucination list and the Parakeet filler-word gate) stay where they are and run first, as before.
- Foreign-script filtering only fires when the engine is English-only or you have explicitly chosen English in Settings > Models > Whisper language. Whisper auto-detect and explicit non-English pins pass foreign script through unchanged.
- Pricing, licence system, updater, history persistence, the floating bar visuals.
- Local-only. No audio leaves your machine.

## Beta only

Beta-channel release. No `--announce`, no `latest` tag. Stable channel still serves v0.15.6.
