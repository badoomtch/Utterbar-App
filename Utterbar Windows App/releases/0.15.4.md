# Utterbar 0.15.4 (beta)

Meeting Mode default flips to Whisper Small. Faster transcribes, honest about the trade-off.

## What this fixes

v0.15.3 made Meeting Mode an explicit user choice with Whisper Medium as the recommended Balanced option. On Jay's machine a real 5-minute test meeting through Medium took roughly as long as the recording itself — fine for a powerful workstation, too slow to be a sane no-preference default on the laptops most users actually run. v0.15.4 flips the default from Medium to Small. Medium and Large remain explicit options for users who want them.

## Measurements

Whisper Small on Jay's machine, on real meeting audio, through the same chunked transcribe pipeline production uses (29 s chunks, 2 s overlap):

- Pre-release Step 0 harness, 116.6 s clip → 24.1 s processing → realtime-factor **0.21**
- Pre-release Step 0 harness, 342.2 s clip → 44.7 s processing → realtime-factor **0.13**
- Post-build full-app smoke test, 369.2 s real meeting → 51.7 s processing → realtime-factor **0.14**
- Cold model load on first meeting after launch: ~3 s

For comparison, Whisper Medium on the same machine and a 116.6 s clip took 101.6 s (RTF 0.87) — v0.15.4 Small finished a 6-minute meeting in roughly half the wall-clock time v0.15.3 Medium took on a 2-minute one.

These are one-machine numbers. Your hardware will land somewhere different. The release-notes claim is "comfortably faster than realtime", not a specific RTF.

## What's the trade-off

Whisper Small is honestly less accurate than Medium, especially on proper nouns and unusual words. Step 0 transcripts kept the gist and grammar of the audio cleanly but mangled names — "Dennis Rodman" became "Stars Rodman", "Thierry Guetta" became "Terry Webber", "Mail on Sunday" became "male on Sunday". If your meetings are full of names, jargon, or accented English, pick **Balanced — Whisper Medium** explicitly in Settings → Models → Meeting mode model.

Common-vocabulary English transcribes cleanly. Sentence flow, grammar, and punctuation are all comparable to Medium.

## What v0.15.4 changes

- **Meeting Mode default is now Whisper Small.** The Recommended chip in Settings → Models → Meeting mode model moves from Medium to Small. v0.15.3 users who never picked a model and only have Medium installed will see the picker ask them to choose explicitly — same shape as v0.15.3's behaviour when the default model wasn't installed. One click, then meetings work normally.
- **Catalogue copy reflects the new role.** Small is described as the fastest meeting option with the trade-off called out honestly. Medium is described as Balanced — slower than Small with slightly higher quality.
- **Performance log gains three telemetry fields.** Every meeting's `meeting transcribe complete` log line in `%APPDATA%\Utterbar\logs\` now also carries `provider_used` (`cpu`), `fallback_used` (`false`), and `fallback_reason` (`""`). They're constant in v0.15.4 — Whisper is force-pinned to CPU and the vendored ONNX Runtime is CPU-only — but the field shape is in place so the logs stay coherent across the v0.15.4 → v0.15.5 transition.
- **Step 0 benchmark harness lands in tree.** A pair of `#[ignore]` tests in `services/inference/sherpa_whisper.rs` run the same chunked pipeline production uses against a WAV on disk, so future model-default decisions can rerun the same measurement under the same conditions. Run with `UTTERBAR_STEP0_WAV` pointed at a meeting recording; off by default so CI doesn't try to find a 600 MB model bundle.

## What's the same

- The Meeting Mode allow-list — Small / Medium / Large v3 only — is unchanged. Parakeet, Zipformer, Whisper Base, and unknown ids remain rejected.
- Dictation Mode (non-meeting) is unchanged.
- Pricing (£39.99 GBP one-time Pro), licence, updater, history, modes, file transcription, floating bar — all unchanged.
- Speaker diarisation is still disabled.

## If you upgrade and your first meeting asks you to pick a model

That's the same v0.15.3 behaviour, now triggered by a different default. If you only have Medium installed (the v0.15.3 default), Meeting Mode in v0.15.4 asks you to either install Small or pick Medium explicitly. Open **Settings → Models → Meeting mode model**, click the row you want, and meetings work normally. One-time setup.

If you preferred v0.15.3's Medium-default behaviour, pick **Balanced — Whisper Medium** in the picker and Meeting Mode keeps using it.

## What's deferred

- **DirectML / GPU acceleration for Whisper.** The vendored ONNX Runtime ships the CPU provider only — `onnxruntime_providers_dml.dll` and `DirectML.dll` aren't in `runtime/`, so DirectML isn't structurally available even if the code requested it. v0.15.5 will revisit: ship the DirectML runtime, validate against all four model engines, add a CPU fallback path with the telemetry fields v0.15.4 reserved.

## Beta only

Beta-channel release. No `--announce`, no `latest` tag. Stable channel is intentionally unchanged.
