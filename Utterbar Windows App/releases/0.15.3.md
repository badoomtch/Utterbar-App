# Utterbar 0.15.3 (beta)

Meeting Mode performance — explicit model choice, no more silent slow path.

## What this fixes

In v0.15.2 Meeting Mode silently routed every meeting through Whisper Large v3 — the slowest model in the catalogue. On a powerful machine that meant transcribing a 5-minute meeting took longer than the recording. On a typical laptop it would be worse. v0.15.3 replaces that silent default with an explicit user choice and adds a faster default option.

## What v0.15.3 does

- **Meeting Mode model is now an explicit choice** in Settings → Models. Three options:
  - **Fast — Whisper Small** (~640 MB)
  - **Balanced — Whisper Medium** (recommended, ~1.9 GB) — new in v0.15.3
  - **Best accuracy — Whisper Large v3** (~1 GB tarball, larger on disk)
- **Whisper Medium is the recommended Balanced option.** If Medium is installed and you haven't set a meeting model preference, Meeting Mode uses it. Otherwise — fresh install with no Whisper model on disk yet, or you're upgrading from v0.15.2 with only Whisper Large installed — Meeting Mode asks you to choose and install a model from Settings → Models. The Meeting card's Install button now shows real-time download progress (the Medium tarball is ~1.9 GB).
- **No more silent Large fallback.** If you upgrade from v0.15.2 with only Whisper Large installed, your first meeting in v0.15.3 will refuse to start and direct you to Settings → Models to pick (or install) a meeting model. This is intentional — the whole point of v0.15.3 is to stop dragging existing users through the slow Large path by default. One click in Settings to pick what you want, then meetings work normally.
- **No more silent Small fallback either.** Whisper Small only runs if you explicitly pick it.
- **Meeting Mode only accepts Whisper Small, Medium, or Large v3.** No other model type is allowed for meetings, even by hand-editing `settings.json` to a different id. Parakeet, Zipformer, Whisper Base, and any future ASR id are all rejected with a clear *"Your meeting model setting is invalid"* error directing you back to the picker. The contract is "Whisper for accuracy on long recordings"; the allow-list enforces that contract from end to end.
- **Success pill shows the model used.** The bar's "Saved" pill now reads `Saved · 5:01 · Whisper Medium · 11 chunks · 799 chars` so you can correlate quality vs speed across meetings without opening logs.
- **Meeting-level performance logging.** Every meeting now writes one summary line to `%APPDATA%\Utterbar\logs\` with audio duration, total processing time, realtime-factor (processing/audio), selected model, chunk count, and Whisper language setting. Lets us collect honest performance data across the beta soak.

## What's also fixed

- **Latent 1-second-per-chunk audio loss.** sherpa-onnx's offline Whisper recogniser silently truncates inputs ≥30 seconds with a stderr warning. Pre-v0.15.3 the chunker passed exactly 30s buffers in the non-final case and lost up to 1 second per chunk on the boundary. v0.15.3 tightens chunk size to 29 s and the cap recomputes accordingly. New transcripts are bit-tighter on the boundary; existing v0.15.2 transcripts in your history are unchanged.
- **Cap of about 60 minutes preserved.** With the 29 s chunk size the cap is 135 chunks = 60 min 47 s. Standard 30 / 45 / 60 min meetings still fit comfortably.

## Settings drift mid-recording is now ignored

In v0.15.2 a recording started as Meeting could in theory stop as non-Meeting if the user changed their active mode mid-recording. v0.15.3 binds the recording session at start time: a recording started as Meeting stops as Meeting, the meeting model used at stop is the one approved at start. Settings drift mid-recording affects the next recording, not the in-flight one.

## What's the same

- Dictation Mode (non-meeting) is unchanged.
- Pricing (£39.99 GBP one-time Pro), licence, updater, history, modes, file transcription, floating bar — all unchanged.
- Speaker diarisation is still disabled. The architectural rework (previously planned for v0.15.3) is now planned for v0.15.4. v0.15.3 is the performance fix; the diarisation rework is the next thing.

## If you upgrade and your first meeting refuses to start

That's expected when you have only Whisper Large installed and haven't set a Meeting Mode preference yet. Open **Settings → Models → Meeting mode model**, pick **Balanced — Whisper Medium** (recommended), click Install if you haven't already, then start the meeting again. One-time setup; meetings work normally afterwards.

If you'd rather keep using Large, pick **Best accuracy — Whisper Large v3** instead. v0.15.3 won't auto-pick it for you, but it works the same as before once selected.

## Whisper language reminder

The "set Whisper language to English" workaround from v0.15.1 still applies. Settings → Models → Whisper language → English (or whatever your meeting language is) → restart. Stops Whisper from inventing foreign-script content on quiet or music-heavy audio.

## Beta only

Beta-channel release. No `--announce`, no `latest` tag. Stable channel is intentionally unchanged (still serves v0.12.0). Speaker labels stay disabled until the v0.15.4 architectural rework ships.
