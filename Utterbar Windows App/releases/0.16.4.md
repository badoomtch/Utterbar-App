# Utterbar 0.16.4 (beta)

Small text-output beta on top of 0.16.3. Stable channel still serves 0.16.0.

## What this changes

This release adds a single new toggle to Settings, Text Output, Formatting:

- **Smart rewrite (off by default).** When you turn it on, Utterbar tidies your dictation before it lands in the focused app. The rewrite is fully local and rule-based: no AI model is loaded, nothing is sent to a server, and no model is downloaded.

What the rewrite does:

- Removes common filler words like "um", "uh", "like", "you know".
- Normalises spacing (collapses runs of whitespace and trims edges).
- Capitalises the first letter of each sentence.
- Adds a terminal full stop if the sentence ends without one.

What the rewrite does not do:

- It is not the future local-LLM rewrite system. There is no model behind it.
- It is rule-based, so it does not understand context. Code dictation is the most obvious blind spot: the same rule that capitalises sentence starts will also capitalise keywords like "let" or "fn", and the terminal full stop will be added after a closing brace. If you dictate code, leave the toggle off.
- It is best for chat and email-style dictation, where filler removal and a final full stop are usually what you want.

## What this does not change

- Meeting Mode is unaffected and remains verbatim. Meeting transcripts are reference material; fidelity matters more than polish, and the toggle does not reach the meeting transcribe path.
- The history view continues to store both the raw transcript (what the speech model produced) and the processed text (what was actually inserted). You can still see the difference per row.
- No changes to ASR models, the DirectML provider policy, runtime DLLs, or any vendor library.
- No new settings, no new policy keys, no schema or licence changes.
- No telemetry, no remote calls, no cloud service.

## Beta only

Beta channel only. No `--announce`. No `latest` tag. Stable channel still serves 0.16.0.
