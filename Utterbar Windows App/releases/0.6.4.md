# Utterbar 0.6.4

The stability release. Everything since 0.6.0 in one go — the crashes from 0.6.1, a redesigned History page, a polished floating bar, and honest memory-safety fixes in the parts of the code that talk to Windows.

## Fixed — stability

- **Crashes on repeated dictation.** A single hotkey press was silently invoking the start-recording command multiple times under the hood, which raced three microphone streams and a native model build in parallel and reliably corrupted the app's memory. One press now means one recording, full stop.
- **Crashes 30–60 seconds after use.** A second class of crashes, this one caused by the way the app was talking to Windows' accessibility API from whatever thread happened to be free. Windows is strict about which thread owns which COM apartment, and we were breaking that contract; now we have a single dedicated thread that owns it for the app's lifetime. The sherpa-onnx recogniser also used to get dropped while another dictation was still holding a reference to it — both code paths are fixed.
- **New recordings can't start while the previous is still transcribing.** Tapping the hotkey mid-transcribe used to start a second recording that raced the first through the inference engine. You now get a quick accent-border flash on the floating bar as a "noted, wait a moment" cue, and the next press once transcribe finishes starts cleanly.
- **The start / stop cue played up to six times per press.** Same underlying cause as the first crash class. Gone.
- **Hotkey silently stops working.** If an earlier recording didn't close down cleanly, subsequent hotkey presses would do nothing until you restarted the app. There's now a self-heal: if the recording or transcribe guard is stuck for longer than it should be with nothing actually running, the app recognises the stale state and starts the new recording anyway.
- **Transcription making up filler words.** If you tapped the hotkey by accident or stopped too early, the transcriber sometimes inserted a phantom "yeah" / "so" / "mm" / "uh" from the room tone. Those are now caught and dropped before anything reaches your clipboard.

## Fixed — UI

- **History page redesigned.** One full-width column of entries instead of a cramped two-column split that used to squeeze the list to ~200 px on normal window sizes. Click any entry to open the detail — raw transcript, processed output, reprocess-as-mode, context inspection — in a modal. Works at any window size, dismisses with Escape.
- **Floating bar opens and closes in one smooth motion.** Width, icon opacity, and icon position now share a single 280 ms timeline instead of running on three separate springs that finished at different times. No more staggered stages on hover-in, hover-out, record start, or record stop.
- **Floating bar border stays lit cyan for the entire drag.** The accent ring comes on the instant you click-and-hold and stays on until you let go — previously it flashed for a split second and vanished because a synthetic pointer-up event was clearing the state mid-drag.
- **Floating bar expanded state has a drag handle.** The centre of the expanded pill is intentionally empty so you can grab it to move the window without accidentally clicking a button. The logo and wordmark sit on the left, the action cluster sits on the right, and the space between is yours.
- **Floating bar collapsed state fits its content.** The closed pill used to float the logo + "Utterbar" wordmark inside a wide expanse of empty gradient; now it hugs tight.
- **Main window scrollbars cleaned up.** At most one scrollbar per column at any window size — previously a third bar could appear on narrow widths, scrolling the left menu from the wrong place. Sidebar footer stays visible on short windows too.
- **Floating bar icons ease out smoothly when you move off.** Before they just popped out of existence.
- **In-app Pro price fallback** corrected from $29 to £39.99 on first launch before the real price arrives from the server.
- **Free-tier "Full history is Pro" message fits on screen** — now a full-width card above the list rather than a cramped half-width nag that wrapped one word per line.
