# Utterbar 0.19.1 (beta)

The first beta on top of v0.19.0. Stable channel still serves v0.19.0.

## Read this first

This is a beta. Stable users remain on v0.19.0. This beta exists to soak the app-language foundation work and the new dictation-language onboarding step before either is bundled into the next stable cut. If you are happy on v0.19.0, you do not need to install this; if you want to try the new flow, switch the channel in Settings, Updates.

## What this release does

Two user-visible changes land on the beta channel.

- **Onboarding now asks for your dictation language.** A new step appears just before the model picker. The default is Auto-detect, so existing users walking through onboarding again see no change in behaviour. If you pick a non-English dictation language, the next step recommends a multilingual Whisper model, because Parakeet (the default English recommendation) supports English only. The Auto-detect default and the existing English recommendation are unchanged.
- **Settings and onboarding text now flow through a shared English text catalogue.** The main shell, the floating bar, onboarding, and most Settings panes (General, Audio, Bar, Text Output, Accessibility, Privacy, Shortcuts, About, Updates, Advanced, plus the Models page header and Whisper-language card) all render their visible copy from one canonical English catalogue. The wording you see is the same wording you would have seen on v0.19.0; the change is plumbing, not phrasing.
- **The Whisper-language picker on Settings, Models now shares the same list as onboarding.** Pick a language in onboarding and the Settings picker shows the same choice. Pick one in Settings and onboarding sees it next time you visit. The list itself (Auto-detect plus 25 popular languages) is the one Settings has shown for many releases.

## What this release does not change

- **App interface is still English only.** No non-English UI language pack ships in this release. The dictation-language step controls only what Utterbar listens for, not what the app reads as.
- **No speech recognition engine change.** No change to Whisper, Parakeet, or Zipformer.
- **No speech model change.** No new model files, no model removals, no checksum changes for any installed model.
- **No audio capture change.** No microphone routing change. No mic-mute change. The experimental Teams and Discord mic-mute toggles introduced in v0.19.0 behave identically.
- **No GPU acceleration change.** DirectML, CUDA, and CPU-only paths all behave as in v0.19.0.
- **No licence change. No Stripe change. No updater behaviour change. No website change. No analytics, no telemetry, no local LLM rewrite.** Smart rewrite is still the deterministic rule-based pipeline.
- **No new outbound network calls from the desktop app.** Same five outbound calls as v0.19.0.

## If you hit a problem

The app log is at `%APPDATA%\Utterbar\logs\`. If you find a regression on this beta, please email hello@ddraig.dev with:

- the log file from `%APPDATA%\Utterbar\logs\`,
- the language you picked on the new dictation-language onboarding step (or "Auto-detect" if you left the default), and
- the model onboarding recommended on the model step.

That third detail in particular helps us catch any case where the recommendation logic chooses something unexpected for a given language.
