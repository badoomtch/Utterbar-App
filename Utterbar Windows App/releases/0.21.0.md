# Utterbar 0.21.0

A big update to Meeting Mode, a new English model, and a tidier set of options. If you have been on the stable channel, this brings everything from the recent beta releases together in one step.

## Meeting Mode is much better

**Meetings now transcribe live, as you talk.** Before, Utterbar recorded the whole meeting and only started transcribing when you pressed stop, so a long meeting could leave you waiting a few minutes afterwards with the app tied up. Now the transcript builds up during the meeting: a live panel appears in the main window and fills in line by line as people speak. Because the work happens while you are still in the meeting, stopping is quick.

**You can see who said what.** Utterbar records your microphone and the other people (the system audio) as two separate sides and labels them, so the transcript reads as a back-and-forth. You can rename the speakers afterwards on the Meetings page.

**Quiet stretches stay quiet.** When one side goes silent while the other person talks, Utterbar no longer invents text that was never said. It only transcribes the parts where someone is actually speaking on each side.

A couple of things worth knowing:

- **Keep the main window open** during the meeting to watch the transcript build. You can close the live panel with the X in its corner, and it comes back on your next meeting.
- **For the cleanest result, wear headphones.** If you use speakers, your microphone also picks up the other people coming out of them, which can double up their words.
- **It is still fully on-device.** Nothing about your meeting is sent anywhere. This is the same local transcription, just done as you go.

## A new English model: Parakeet v2

Parakeet v2 is fast on any modern computer and tuned purely for English. In everyday dictation it is very close to Parakeet v3, and it scored at the top of the open speech-recognition benchmarks when it was released. Pick it if you dictate in English only and want to try it. Install it from Settings, Models. It is free, and Parakeet v3 stays the recommended default.

## Tidied up

**Whisper Turbo has been removed from the model list.** The list had grown crowded and Whisper Turbo overlapped with the models around it. Whisper base, small, medium, and large v3 still cover multilingual dictation, and Parakeet covers fast English. If you already installed Whisper Turbo, nothing on your machine is deleted.

**The graphics acceleration options are simpler.** Settings, Advanced used to list a CUDA option that Utterbar never actually used, so choosing it quietly ran on your processor anyway. It is gone. The choices are now Auto (recommended), DirectML, and CPU only. If you had CUDA selected, Utterbar now uses the recommended Auto setting.

## What this release does not change

- **No change to everyday dictation.** Single-shot dictation and your text settings behave exactly as before. The Meeting Mode changes only apply when a mode is flagged as a Meeting.
- **No change to the App language picker, and no new interface languages.**
- **No change to the licence system, Stripe, or the price.**
- **No new outbound network calls from the app** beyond downloading a model when you choose to install one.

## If you hit a problem

The app log is at `%APPDATA%\Utterbar\logs\`. Email hello@ddraig.dev with the log file and a short description.
