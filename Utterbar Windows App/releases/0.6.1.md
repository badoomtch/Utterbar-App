# 0.6.1

Polish + the in-app updater. No new gated features — everything here either removes friction or lets you stay inside the app for things that used to require a browser trip.

- **In-app auto-update.** When a new release lands, a small toast appears bottom-right on launch with "Install & restart". One click downloads the installer to `%TEMP%`, SHA-256 verifies it against the server's canonical hash, runs the silent NSIS install, and relaunches you on the new version. No browser round-trip, no manual installer babysitting. You can also kick it off manually from Settings → General → App updates → **Check now**.

- **Custom accent colour (Pro).** Picking "Custom" in Settings → General → Accent opens the native colour picker. We derive a full tint/shade gradient from your one hex so surfaces that use the accent family (wordmark, pill glow, CTA buttons) still have depth instead of painting everything in one flat colour. Free users see a Sparkles-badged chip that opens the upgrade modal; the six preset accents stay unchanged on Free.

- **In-app upgrade modal.** Clicking a Pro-gated action (e.g. New mode, Duplicate mode, Custom accent) now opens an upgrade modal inside the app showing the live price (fetched from the server, with an offline fallback of $29 one-time) and a direct "Upgrade to Pro" CTA. Previously every gated click punted you straight to the browser.

- **Floating bar: actually compact Compact.** The smallest bar size now shrinks height, icon size, and text proportionally — not just padding. The "Ready" label is more readable at every size, and collapsed compact shaves ~24 px off the minimum width so the bar footprint matches its "get out of the way" job.

- **History page.** Responsive padding at narrower widths, a smarter empty state that distinguishes "no matches for this search" from "nothing recorded yet", and the detail pane no longer eats a second viewport on narrow windows when nothing's selected.

- **Release asset filenames carry the version.** Every installer in R2 is now `Utterbar-Setup-<version>.exe` (e.g. `Utterbar-Setup-0.6.1.exe`). Makes old temp/download folders self-documenting and rules out any "wait, which version did I install?" ambiguity.

- **Settings navigation.** The left-nav now scrolls independently of the content, so About and Upgrade are always reachable, and the app no longer shows two stacked scrollbars.

Fixed:
- Paper-theme logo: the dark title-bar pill now tracks the app theme, so the window chrome stops looking detached from the content on the cream Paper theme.
- Toggle primitive: standardised all settings toggles on the canonical `<Toggle>` component — no more white-on-state divergence between pages, and the sizing no longer drifts between sections.
- Release-email signup: client-side email syntax check before we make the network round-trip, plus a friendly error if the server ever returns non-JSON (e.g. gateway timeout HTML).
- Licence survives installer upgrade. Your activation is stored in Windows Credential Manager via DPAPI; the `%APPDATA%\Utterbar\settings.json` and database live outside the install dir. NSIS's "uninstall previous version" step no longer takes your Pro licence with it. (This was already true — 0.6.1 adds defensive documentation and upgrade-survival tests so it stays true.)
