# Utterbar 0.16.2 (beta)

Small beta reliability and UX improvement on top of 0.16.1. Stable channel still serves 0.16.0.

## What this changes

This release focuses on the wait you feel before your first dictation after launching Utterbar. The cost of loading an ASR model into memory has not gone away, but Utterbar is now smarter about when it pays it.

- **Background prewarm of the default dictation model.** If you have set the model warm-up duration to "keep loaded" in Settings, Models, Utterbar now starts loading your default dictation model in the background a moment after launch. Your first dictation after starting the app should land on an already-warm model instead of paying the cold load there.
- **Startup is not blocked by the prewarm.** The window, tray, and floating bar appear at the usual time. The prewarm runs after the UI is up.
- **If the prewarm fails, the app still opens normally.** Your first dictation will then load the model on demand, exactly as before. The failure is logged at warn level in `%APPDATA%\Utterbar\logs\latest.log` so support can read it.
- **Structured timing for ASR cold model warm-up in logs.** When the model loads for the first time, Utterbar now records the file resolve time, the native sherpa-onnx construction time, and the total warm time as separate fields in the log. This makes it easier to tell where time is going when a load feels slow.

## What this does not change

- This does not make the native ONNX or sherpa model construction itself any faster. The work is the same; it is just shifted off your first dictation when you have asked for the model to stay loaded.
- DirectML cold warm can still be expensive, especially on the first launch after a reboot when the GPU driver state is cold. The prewarm shifts that cost off your first dictation but does not remove it.
- Meeting Mode model prewarm is not included in this release. Only the default dictation model is prewarmed today.
- No change to the DirectML provider policy. The auto-Small-prefers-CPU rule from 0.15.6 is unchanged. No model files, no runtime DLLs, and no vendored libraries have changed.
- No new settings, no new policy keys, no schema or licence changes.

## Beta only

Beta channel only. No `--announce`. No `latest` tag. Stable channel still serves 0.16.0.
