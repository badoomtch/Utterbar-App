# Utterbar 0.12.1 (beta)

A Settings clarity pass. Four UI fixes, no new features. Beta-channel only — promotes to mainline (0.13.0) once it has soaked.

## Settings → Licence: licence key now hides by default

Your Pro key sits behind a Show button instead of being printed in plain text. Click Show to reveal it; auto-rehides after 30 seconds so an unattended screen doesn't leak the key. Copy still works whether revealed or hidden. Screen readers always read the real key on focus, so accessibility isn't degraded.

## Settings → Modes: clearer output-style picker

The "Post-processing" section is renamed **Output style** and the chip labels are now **Plain** and **Templated** instead of "none" and "deterministic". A short blurb under the chips explains what each one does to your transcribed text.

The Templated format field gets:
- Help text underneath: *"Use {text} where the dictation goes. Anything else is added literally."*
- A live **Preview** row that shows what your format string produces with a sample sentence. Type `"💬 {text}!"` and immediately see the result `"💬 Hello world!"` without having to dictate.

The mode list in Settings → Modes now reads "Built-in · Plain" or "Custom · Templated" instead of the engineering terms.

## Settings → Modes: real icon picker

The "Icon (lucide key)" text input has been replaced with a grid of 24 icons grouped by use-case (communication, writing, work contexts, general). Click the one you want. The label is now just **Icon**.

Existing modes keep their current icons. Custom modes that previously used invalid icon names will now render a Sparkles fallback rather than a bullet point.

## Settings → Modes: rebuilt auto-activation editor

The auto-activation rule editor has had three problems for a while:
- Match-type labels were raw enum values ("exe", "title", "class").
- No empty state, so a mode with zero rules left you to guess at the shape.
- No feedback whether a rule would actually fire.

All three fixed.

The dropdown now reads **Exe name**, **Window title**, **Window class**, with a contextual hint underneath that changes with the selection. Placeholders are realistic examples (`outlook.exe`, `*Outlook`, `rctrl_renwnd32`).

A mode with no rules now shows three illustrative examples so you can see the shape before adding your first.

The big change — every rule with a non-empty pattern now shows a live indicator:

    ● Currently focused: outlook.exe · matches

The dot turns green when your rule fires against the focused window. Alt-tab between apps and watch the indicator update in real time. No more "save, dictate something, hope it activates the mode".

## Behind the scenes

A new IPC command `current_focused_window` exposes the foreground window's exe/title/class to the editor. Reuses the same plumbing the auto-activation watcher uses internally, so the live indicator matches what the runtime would actually trigger on.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to `hello@ddraig.dev` and we'll take a look.
