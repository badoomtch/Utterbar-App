# Utterbar 0.18.0

A small visual stable on top of v0.17.0. Bundles the soaked v0.17.1 and v0.17.2 betas, both narrow tunes to the floating-bar waveform.

## What this changes

The seven bars in the floating bar's recording cluster are now noticeably more responsive to your voice and form a clearer Utterbar-logo silhouette while you are speaking:

- **More visible movement on quiet and normal speech.** In v0.17.0 the bars sat near the bottom of their range for a typical user voice. v0.18.0 lifts them so conversational volume drives the bars closer to the upper rail, and soft speech now shows real movement instead of barely flickering.
- **Logo-shape silhouette.** The middle bars climb higher than the outer bars, so a typical voice draws the same "mountain peak in the middle" shape you see in the Utterbar logo, instead of all seven bars rising to roughly the same height.
- **Silence still sits low.** Dead air keeps the bars at the bottom row, so the bar never falsely says "I'm hearing you" when it isn't.
- **Reduced motion behaviour is unchanged.** If you have Windows reduce-motion enabled (or the in-app accessibility setting), the bars still freeze at a static row exactly as before.

## What this does not change

- **Speech recognition accuracy is unchanged.** Only the visual responsiveness and silhouette of the floating-bar waveform is different. The audio Utterbar listens to and the text it produces are exactly the same as v0.17.0.
- **No changes to audio capture or microphone routing.**
- **No changes to the speech engine or the speech models.**
- **No changes to GPU acceleration.**
- **No telemetry or analytics added.** Utterbar still sends nothing about your usage to us.
- **True per-app microphone mute is still NOT in this release.** Output-audio mute only, same as v0.17.0.

## Stable channel

This release supersedes v0.17.0 on the stable channel. Beta-channel users on the v0.17.x line will see 0.18.0 as the next available update. The v0.17.1 and v0.17.2 beta rows remain in admin as historical soak records. If you have been running a beta and want to stay on stable from now on, switch the channel in Settings, Updates after upgrading.

## If you hit a problem

The app log is at `%APPDATA%\Utterbar\logs\`. If Utterbar crashes, `crash.log` in that folder will have details. The dictation log lines record which speech model and provider (GPU or CPU) ran each attempt, which helps support diagnose issues quickly. If a feature misbehaves, try switching Settings, Advanced, GPU acceleration to CPU, then email hello@ddraig.dev with the log file. It helps if you mention whether the issue happens at start-up, just after an update, or only during dictation.
