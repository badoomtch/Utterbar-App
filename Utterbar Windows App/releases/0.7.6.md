# Utterbar 0.7.6

A small touch: a discreet "Tip the developer" surface on Settings → Licence for Free users. Pro users don't see it — you've already paid.

## Tip the developer

- **New surface on Settings → Licence (Free state only).** £3 / £5 / £10 / Custom buttons that open the website's tip checkout in your default browser. Voluntary, no perks, no licence — just thank-you money. Opens Stripe-hosted Checkout for the actual payment.
- **Pro users see nothing.** If you're already on Pro, the licence page hides the tip card — surfacing it would feel like asking twice.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log and any crash dumps. Send the newest files to support and we'll take a look.
