# Utterbar 0.14.3 (beta)

Meeting mode picks Whisper Large automatically when it's installed. Wrong speaker labels removed from the transcript until the next iteration. Beta channel.

## Meeting mode now auto-routes to Whisper Large v3

Pick Meeting mode and the dictation flow uses Whisper Large v3 for the transcribe, regardless of what the global default model is set to. The mode itself implies "best accuracy regardless of speed", and switching the global model dropdown manually for every meeting was friction nobody asked for.

If Whisper Large v3 is not installed, Meeting mode silently falls back to your global default model. The mode editor now tells you which path is active:

- Whisper Large installed: `Meeting mode uses Whisper Large v3 for best accuracy.`
- Not installed: `Meeting mode uses Whisper Large v3 when installed. Install it in Settings → Models for best meeting accuracy.`

The auto-route applies consistently across the cold-load Warming pill, the Initialising-model copy, the actual transcribe call, and the saved metadata on the history row. The early probe and the final transcribe now resolve through the same code path so they cannot disagree.

## Speaker tags suppressed (temporarily)

In v0.14.2 every chunk was tagged either `**You**` or `**Other**`. The heuristic was wrong on real recordings: in typical setups the mic picks up bleed from the speakers, the loopback can be empty (output device is headphones, Bluetooth, or virtual routing), and the threshold scaling was on mean-square not RMS. The result was tags that looked authoritative but said the wrong thing.

In v0.14.3 the transcript shows just the timestamp:

```
[00:00] So this is going to be a test of whether this works at all...
[00:30] Super tired I woke up at 3 in the morning...
```

No speaker label. Honest about what the app actually knows.

The per-side energy values are still calculated and written to the log so the next release has real-recording data to tune against. The proper signal-above-baseline heuristic is the v0.14.4 work.

## If something does go wrong

`%APPDATA%\Utterbar\logs\` has the app log. `crash.log` has any panic traces. Send the newest files to `hello@ddraig.dev`.
