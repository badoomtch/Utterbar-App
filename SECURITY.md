# Security Policy

## Report Privately

Email **[jay@jayparry.me](mailto:jay@jayparry.me)** with the subject
`Utterbar security report`.

Do not put exploit instructions, credentials, private recordings, clipboard
contents or unredacted logs in a public issue. Include the affected version,
reproduction steps, likely impact and a minimal non-sensitive example.

No response-time guarantee or bug-bounty programme is offered. Allow time to
investigate and coordinate a fix before public disclosure.

## Releases and Downloads

Security fixes target the latest stable release. Betas are testing builds;
older versions may require updating rather than receiving backported fixes.
See [GitHub Releases](https://github.com/badoomtch/Utterbar-App/releases).

Only download installers from this repository's Releases page. Installers are
currently unsigned. A GitHub download or matching digest is not a guarantee
that software is free of vulnerabilities.

Local data lives under `%APPDATA%\Utterbar\`. Logs, history and recordings can
be sensitive. Redact diagnostics before sharing and back up before resetting.
